# 期望与标签的自证效应

## R — 原文 (Reading)

> "自我实现预言（self-fulfilling prophecies）指对于未来行为或事件的预测会改变人们的互动行为，以至于得到预期的结果。"
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第16章 社会心理学 > 建构社会现实 > 期望与自我实现预言

---

## I — 方法论骨架 (Interpretation)

期望不是"心里相信他行"就起作用，它必须**转成四个可见行为**才能改变对方表现（罗森塔尔拆解）：
1. **氛围**：更多热情与友好，制造社会赞许与接受的氛围（降低威胁感）；
2. **标准**：提出更高要求，尤其是材料的质量与难度——降要求是最常见的隐性否定；
3. **反馈**：更直接、更清晰的反馈（表扬和批评都要，模糊鼓励无效）；
4. **机会**：创造更多公开表现场景，让对方拿到"我确实行"的确凿证据（闭环）。

同一机制在三个层面放大：
- **行为确认**：你对某群体的预期，会制造出让对方做出符合刻板印象行为的氛围。
- **刻板印象威胁**：同样的测验，只要把情境定义成"在测我的能力"，属于负性刻板印象群体的人成绩就掉——且**可被引导语消除**，不是固有能力差。
- **标签自我实现**：一旦被标定（IQ 分数、诊断、污名），后续一切都成了印证标签的证据。

关键边界（作者明确）：实验室里故意给错误期望才证明效力；**现实里大多数期望基于准确的社会知觉**，所以正确用法不是"无条件瞎夸"，而是在期望**可能无据可依**（新人、陌生群体、刻板印象对象）时格外谨慎，且正向期望的边际收益在被低估者身上最高。

## A1 — 书中的应用 (Past Application)

### 案例 1: 罗森塔尔的"聪明大鼠"与"学习苗子"
- **问题**: 实验者的期望会不会改变结果？
- **方法论的使用**: 学生以为分到"擅长走迷宫"的大鼠（实际一样），结果符合预期；人类版中，随机点名"学习苗子"的学生，学年末 30% 智商平均涨 22 分。
- **结论**: "标记为聪明"→ 对待方式改变 → 表现真的变好。
- **结果**: 客观成绩改变（非主观感受），证明期望效应的真实力度。

### 案例 2: 归因干预提高成绩（Walton & Cohen）
- **问题**: 少数族裔新生成绩偏低，是能力问题吗？
- **方法论的使用**: 只把"我融入不了"从内部稳定判断，改写为"人人都经历、会随时间消退的普遍现象"，不改任何实质能力。
- **结论**: 实验组实际成绩高于由其历史成绩推得的预期，控制组低于预期。
- **结果**: 只改解释就提了成绩——证明表现差常是被主导归因拖住，而非能力。

### 案例 3: Farina 的拒绝预期实验（污名自我实现）
- **问题**: 被标记者表现差，是因为"病"还是因为"被标记的预期"？
- **方法论的使用**: 曾住院男性一半以为对方知道自己病史，一半以为对方不知；"实习生"其实完全盲分组。
- **结论**: 以为自己被标记者说话更少、作业更差，连不知情的同谋也把他们评得更"紧张焦虑"。
- **结果**: 预期 → 行为改变 → 引发他人真实负面反应，形成完整闭环。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 带团队 / 教书 / 带新人 / 辅导，想提升某人表现。
2. 给孩子、下属、学生做定性（"他不行""他聪明"）。
3. 设计测评、考试、考核、招聘，担心框架影响结果。
4. 看到某群体表现差，想判断是能力还是被情境暗示。
5. 识别"我早知道他会这样"是不是自己参与制造的结果。

### 语言信号（用户的话里出现这些就应激活）
- "我看好他 / 这孩子不行 / 他就是这性格"
- "分班 / 贴标签 / 给他定性"
- "女生（或某群体）就是弱 / 不擅长"
- "刻板印象 / 自我实现预言 / 罗森塔尔"
- English: "self-fulfilling", "stereotype threat", "Pygmalion", "labeling effect"

### 与相邻 skill 的区分
- 与 `situational-force-audit` 的区别: 本 skill 是**你个人的期望/标签**塑造了具体某个人的表现；situational-force-audit 是**群体结构性规范**（从众、服从、群体极化）塑造集体行为。
- 与 `persuasion-and-compliance` 的区别: 本 skill 改变的是**长期自我形象与表现**；persuasion 改变的是**单次态度与行为**。
- 与 `abnormality-boundary-judgment` 的区别: 涉及"他是不是有心理疾病"的判定，交给后者；本 skill 只处理期望/标签如何影响普通表现。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **识别你正在对谁持有何种预期**
   - 完成标准: 能明确说出"我对 X 的预期是___，它可能影响我的对待方式"。

2. **把预期翻译成四个动作**
   - 完成标准: 分别检查氛围（热情/友好）、标准（难度不降档）、反馈（具体清晰）、机会（公开表现）四项是否到位；缺项即补。

3. **优先投给被低估者**
   - 完成标准: 对低成就 / 新人 / 刻板印象对象，正向期望边际收益最高；避免"保护性低期望"（只给边缘任务、逐行检查）。

4. **排查刻板印象威胁（测评 / 考核前）**
   - 完成标准: 施测说明不含群体差异表述；框架改为"非诊断性"（用于定位提升方向，不作晋升依据）；不当场采集身份类别后再测。

5. **警惕负向期望与标签**
   - 完成标准: 不拿刚学到的诊断/类型学对亲友定性；用具体行为事实沟通，必要时转介专业评估（见 abnormality-boundary-judgment）。

6. **自我审查：是不是我在制造这个结果**
   - 完成标准: 当你想说"我早就知道他会这样"时，先查自己的对待方式（氛围/标准/反馈/机会）是否参与了制造。

判停条件（进入前先判）: ① 若用户的诉求是"确认他有病／给他定性" → 终止本 skill，移交 abnormality-boundary-judgment；② 若用户把对方表现差归因成"他自己信了自己不行"并以此免责 → 终止本 skill，改用 attribution-audit；③ 若问题出在群体规范而非个人期望 → 终止本 skill，移交 situational-force-audit。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **责怪受害者**: 不能说"是你自己信了才这样的"。标签拉低表现是真实的机制，不是当事人的责任。
- **自行诊断**: 若话题走向"他是不是有心理疾病"，立即移交 abnormality-boundary-judgment，且不得给出任何诊断结论。
- 用正向期望替代实质资源：四步动作是放大器，不是替代培训、工具、时间的借口。

### 作者在书中警告的失败模式
- **IQ 分数的自我实现**（CE35）: 分数一旦决定分班/资源，就通过环境改变动机与自我效能，自我兑现；分数被当成固定印记会压低挑战寻求。
- **诊断标签的自我实现**（CE42，罗森汉恩）: 标签贴上后，理性讨论→"理智化"、记笔记→"书写行为"、连治愈都写进疾病叙事；逻辑上不可推翻。
- **刻板印象威胁**（CE36）: 提醒身份差异这件事本身就会拉低表现，且通过改变指导语即可消除——说明分数里混入了与能力无关的成分。

### 作者的盲点 / 时代局限
- 自我实现预言与刻板印象威胁的多数经典研究基于 WEIRD 样本；跨文化推广须谨慎。
- 书中所举"白人/亚裔/女性"等群体差异实例，反映的是特定社会语境下的刻板印象，引用时勿当成普适人性。

### 容易混淆的邻近方法论
- 用"群体规范压力"解释时用 situational-force-audit；用"单次说服"解释时用 persuasion-and-compliance。
