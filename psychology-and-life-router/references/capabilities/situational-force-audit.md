# 情境力量审计

## R — 原文 (Reading)

> 仅仅以运气（即随机分配的形式）决定了参与者的角色是狱警还是囚犯。角色创造了在监狱情境中行之有效的地位和权力差别。……米尔格拉姆进行了一系列的研究，发现盲目的服从与其说是性格特质的产物，倒不如说是吞噬每个人的情境力量作用的结果
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第16章 社会心理学 > 情境的力量

---

## I — 方法论骨架 (Interpretation)

把一个群体里"人怎么会这样"的问题，从人格解释换成结构解释。全书最后一章做的是一次纠偏：好人和坏人的分界线，经常不画在人身上，而画在情境的几条参数上。这些参数是可审计、可拧动的：

**1 角色。** 随机分派的角色就足以改变行为，而角色不需要教导——人会从已有的社会互动经验（父母/子女、教师/学生、医生/病人、老板/工人）里提取并强化模式。所以"招好人"不能替代"设计好角色"。

**2 规范。** 规范不可见，只能从两条线索反推：一致性（多数成员在哪些方面行为整齐划一）与惩罚（有人越界后到底发生了什么，越界的后果才是规范的真正边界）。规范有极强惯性，会跨代传递，换人不等于换规范。

**3 从众。** 两条独立通路，破解方式完全不同：信息性影响（我怕我错了）→ 引入外部事实标准与专家意见，把模糊情境变清晰；规范性影响（我怕被排斥）→ 给异议者一个同盟。规模参数：3–4 人的无异议多数就足以产生从众；反过来，一个同盟就足以显著恢复独立性。

**4 群体决策。** "讨论之后大家的看法变强了"不等于"信息变多"。两个引擎在同时做功——信息引擎（每个人都只贡献支持初始倾向的论据）与社会比较引擎（都想比群体基准再极端一点以显示自己机敏）。极化方向由群体初始倾向决定，可能更冒险也可能更谨慎。群体思维是第三种故障模式：过滤掉不中意的观点，使其与领导的见解一致。

**5 服从。** 由情境变量而非人格变量控制，所以别做人格筛选（筛不出来）。拧高服从的旋钮：有人先服从形成先例、你只是"协助"而非执行（责任被切割）、受害者距离远（抽象化）、权威在场且唯一。拧低服从的旋钮：受害者本人请求、出现两个互相矛盾的权威、权威自己成为受害者、有明确可见的退出动作。

审计的结论形态是：列出当前情境里哪几条参数被拧到了哪一端，以及要改变行为该拧哪个旋钮、谁负责拧、何时拧——而不是列出"哪些人有问题"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 谢里夫的自主运动效应 — 规范的生成与跨代传递
- **问题**: 在一个完全模糊的知觉情境里，个人判断差异极大，群体如何形成一致判断？这个一致性能不能脱离群体现场存活？
- **方法论的使用**: 全黑背景下静止光点的"自主运动效应"错觉，分三段测——先个人判断，再小组大声说出判断，最后让参与者**独自**回到同一间暗室再测。并做了一个跨代传递变项：每轮换掉一名成员，直到情境中全是新人。
- **结论**: 模糊情境下人把他人的判断当作证据（信息性影响），规范由此结晶；规范一旦形成，就倾向于永久存在下去。
- **结果**: 参与者独自回到暗室后，仍然遵守一起时所形成的群体规范；一年后测试依然如此。跨代传递实验中，经过几代成员的全部更换，群体的自主运动规范依然完好如初。教训是：改一个团队的做事方式，换人没用，必须显式地确立新规范。

### 案例 2: 阿希的线段判断实验 — 事实清晰时的从众
- **问题**: 当客观事实绝对清晰（线条长短差异足够明显，单独判断极少出错）时，人还会不会跟着多数人走？
- **方法论的使用**: 参与者与 6–8 名实验者同谋坐成半圆、自己坐最后；前三轮一致正确，从第四轮起同谋一致给出错误答案；18 次判断中有 12 次面临两难。再变项：无异议多数人的规模、是否出现一位持不同意见的同伴。
- **结论**: 存在两条独立通路。信息性影响下从众是理性的（情境模糊时观察他人确实是最优信息策略）；但即使事实清晰，规范性影响仍然生效。
- **结果**: 约四分之一的人保持了完全的独立性；50%～80% 至少一度从众于多数人的错误估计；三分之一的人在半数或更多的判断中屈从。两个常被忽略的发现：无异议多数人只需 3–4 人，从众效应就已非常明显；而只要出现一位与多数人意见不一致的同盟，从众几率就急剧减少。作者同时给出反面：三分之二的时候参与者给出了正确的、不从众的答案——这个实验既证明了人的从众性，也证明了人的独立性。

### 案例 3: 米尔格拉姆服从实验 — 65% 的人施加了最高电压
- **问题**: 普通人会不会在权威指令下对他人施加致命电击？是人格缺陷还是情境力量？
- **方法论的使用**: 19 个独立实验、超过 1000 名参与者（不同年龄、职业、学历、性别）。操纵的是情境变量——穿白制服的权威在场并说"实验要求你继续""没有选择，你必须继续"、责任被明确转移（"由我负责"）、加害被切成每档 15 伏的小步骤、受害者在一墙之隔。因变量是拒绝服从前施加的最高电压。
- **结论**: 服从由情境变量控制，不是人格变量；不要做人格筛选，去改旋钮。
- **结果**: 达到 300 伏时仍无参与者退出，65% 的人施加了最高值 450 伏。绝大多数人口头抗拒，但在行动上并未反抗——从受害者的角度看差异微乎其微。对照组：40 名精神病医生预测 450 伏时只有约 0.1%。（伯格 2009 年的部分重复在 150 伏处停止：原实验 82.5% 的人在超过 150 伏后继续，重复中 70% 继续。）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 一个组织/团队/社群里出现了重复失效——换了人、换了领导，还是老样子。
2. 会议上没人反对、全票快速通过，或讨论之后的立场比会前更极端。
3. 复盘一次组织丑闻或集体失误，需要判断这是"几个坏人"还是结构性的。
4. 你要设计一套制度：值班表、问责链条、审批流程、举报通道、KPI 与考核口径。
5. 你刚进入一个新群体，需要判断"这里真正看重什么"（不是写在墙上的那种）。
6. 你要在群体里推动一个不受欢迎但正确的意见（少数派如何起作用）。

### 语言信号（用户的话里出现这些就应激活）
- "为什么好人在里面也做坏事" / "换了三拨人还是这样" / "这不是谁的错，是制度问题"（这句要审慎——常常只是换了句道德豁免）
- "会上没人反对" / "大家一致认为" / "气氛特别好，全票通过"
- "我们这儿的规矩是……" / "在这儿大家都是这么干的" / "新人进来就学会了……"
- "老板已经定了" / "上面要求的，我也没办法" / "我只是执行" / "出了事由我负责"
- 英文: "that's just how things are done here" / "nobody raised any objections" / "we all agreed" / "I was just following orders"

### 与相邻 skill 的区分
- 与 `attribution-audit` 的区别: 那个处理"一次已经发生的行为，原因该归给谁"——对象是单个行为，产出是修正后的归因。本 skill 处理"一个群体的行为模式由哪些结构参数维持"——对象是系统设计，产出是要拧的旋钮。问"他为什么这么做 / 我为什么失败"→ `attribution-audit`；问"为什么这里的人普遍都这样 / 怎么让这个群体制止这种事"→ 本 skill。
- 与 `bystander-intervention` 的区别: 那个处理"有一个具体的人正在等待帮助而没人动手"的即时场景，核心动作是把责任个体化（点名到人）。本 skill 处理持续存在的群体结构与规范。判据：有没有一个此刻正在受害/等待帮助的具体对象？有 → `bystander-intervention`；只是在问"这个组织为什么长期这样"→ 本 skill。
- 与 `persuasion-and-compliance` 的区别: 那个处理有明确说服者的场景（中心路径 vs 外周路径、互惠、登门槛、以退为进）；本 skill 处理**没有明确说服者**的结构性压力——角色、规范、从众、服从。有人在推销一个主张时用那个；没人在推销但所有人都这么做时用本 skill。
- 与 `behavior-change-toolbox` 的区别: 那个处理单个个体的行为塑造（强化相倚、程序表、替代惩罚）；本 skill 处理群体层面的结构参数。若你已确定要改的是某个群体的规范，本 skill 给出结构动作后，个体层面的维持可组合 `behavior-change-toolbox`。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **把问题从"人"重述成"位置 + 条件"**
   - 重述格式："在什么条件下，处在这个位置的人会做出 X"。
   - 完成标准: 重述后的句子里没有具体人名，只有位置、条件、行为。
   - 判停条件: 若问题确实是"某个具体的人为什么做了一件具体的事"，转 `attribution-audit`。

2. **画情境图：角色 / 规范 / 权威 / 受害者距离 / 责任归属**
   - 逐项填写：谁被赋予了什么角色；这个群体实际在奖励什么、惩罚什么；指令从谁发出；被伤害的人离决策者有多远（物理距离与被抽象化的程度）；责任是被一个人扛着还是被切成碎片。
   - 完成标准: 五项各有一句具体描述。其中"规范"这一项必须是用**两条线索**反推出来的——多数成员在哪些行为上整齐划一、有人越界后实际发生了什么——不得引用墙上的标语或制度文本。
   - 判停条件: 若此刻有具体的人正在受害且无人出手，先转 `bystander-intervention` 做责任个体化，再回到本流程。

3. **逐引擎排查：从众 / 群体极化 / 服从 / 群体思维**
   - 从众：是信息性的（情境模糊、缺外部标准）还是规范性的（事实清晰仍从众、人不愿被排斥）？
   - 群体极化：讨论后的立场是否比会前更极端？方向由群体初始倾向决定（可能更冒险，也可能更谨慎）。
   - 服从：是否存在权威指令、责任转移话术（"由我负责"）、加害被切分成小步骤、退出需要主动对抗？
   - 群体思维：群体是否凝聚力高、脱离外部专家、由领导直接操纵？会议上是否无人提出反对？
   - 完成标准: 四格各填"存在 / 不存在 + 一条可直接观察到的证据"（会议记录、投票分布、发言顺序、实际处理过的越界案例），不含推测。

4. **给每条被判定"存在"的引擎配一个可拧的旋钮**
   - 信息性从众 → 引入外部事实标准与专家意见，把模糊情境变清晰。
   - 规范性从众 → 给异议者一个同盟（不必是多数，一个人就够，无异议多数只要 3–4 人就足以制造从众）。
   - 极化（信息引擎）→ 讨论前强制收集反方论据并书面分发、先独立提交再汇总。
   - 极化（社会比较引擎）→ 匿名化、先独立打分后公开、把"极端"从被奖励的行为里摘出去。
   - 群体思维 → 会前指定红队、领导最后表态、引入外部专家、给异议提供低社交成本的表达渠道。
   - 服从 → 缩短受害者距离（让决策者直接面对后果）、明确责任归属（拒绝"由我负责"式的责任转移）、设置低成本低社交代价的"停止键"。
   - 完成标准: 每条"存在"的引擎都对应至少一个可执行动作 + 一个指名的负责人 + 一个时间点。
   - 判停条件: 若某条引擎判定"存在"却找不到可拧的旋钮（如权威结构不可更改），明确记录为"结构约束，需升级处理"，不得用"加强沟通""提高意识"这类占位动作充数。

5. **规范变更必须显式化（当结论涉及改规范时）**
   - 完成标准: 新规范有书面表述、有公开宣布的记录、由权威重申过，且至少发生过一次对越界行为的实际处理（没有后果，规范就不存在）。
   - 判停条件: 若团队已完成整体换血，必须明确告知用户"换人不会改变规范"——规范会跨代传递给新人（谢里夫的跨代传递实验）。

6. **验收：用行为数据而不是主观报告**
   - 设计一个可客观读取的行为指标（能耗、出勤、上报率、漏审率、响应时间），做小样本 A/B 或前后对比。
   - 完成标准: 有一个可客观读取的指标 + 一次前后对比。
   - 判停条件: 若只能拿到自我报告，把结论降级为"初步证据"，并援引书中证据——加州节能研究里，居民自评"激励作用最小"的规范性信息，在电表读数上效果最强。**不要问人们"什么会影响你"，直接测行为。**

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 你在解释**一个人的一次具体行为**（他为什么迟到、我为什么搞砸、要不要换掉某个下属）→ `attribution-audit`。本 skill 的产出是制度设计，回答不了"这次该不该怪他"。
- 现场有人正在受害、需要立刻有人出手 → `bystander-intervention`。本 skill 的产出救不了当下。
- 你实际上是在做说服/营销/谈判设计（如何让别人答应你的请求）→ `persuasion-and-compliance`。本 skill 处理的是**没有明确说服者**的结构性压力。
- 你手上有权力且准备用来追责：本 skill 的诊断结论（"这是情境造成的"）极易被误用成"所以没人有责任"。作者本人反对这种读法——米尔格拉姆的参与者"绝大多数人口头抗拒，但在行动上并未反抗"，从受害者的角度看来差异微乎其微。结构解释改变的是预防设计，不改变已发生行为的责任。

### 作者在书中警告的失败模式
- **failure_mode（CE49 群体思维）**: 决策群体过滤掉不中意的观点以保持一致，尤其与领导的见解一致。后果是：所有成员都参与了决策，但决策质量低于任何单个成员独立判断的平均水平（并与群体极化叠加）。
- **mechanism**: 两条驱动。其一，规范性影响——持异议的社会成本（被排斥、被视为不忠诚）在凝聚力高的群体里尤其高，于是**自我审查先于公开讨论发生**，成员还没开口就已经把异议删掉了；所以表面上的"一致同意"是真实存在的，只是它是审查的产物而非共识的产物。其二，共享信息偏差——讨论倾向于集中在大家已经知道的信息上，而"只有某一个人知道的那些信息"最可能被略过，恰恰是这些独特信息能提高决策质量。作者给的解药正对着第二条：**有异议往往能改善群体决策的质量，尽管它从表面上看可能会贬低群体的正面感受**——必须接受短期不适换长期质量。
- **配套警报**: 高风险群体构型是"凝聚力高 + 脱离专家 + 受领导直接操纵"。**"气氛特别好、全票快速通过"是警报，不是安心。**

### 作者的盲点 / 时代局限
- **本书英文版成书于 2014 年，早于 2015 年可重复性危机的大规模重复验证。本 skill 的 R 段引文出自斯坦福监狱实验——这是本书作者津巴多本人的成名作，在 2018 年后被档案研究严重质疑（需求特征、实验者介入、样本自选择），书中仍以正面经典呈现，这是作者最明显的自利盲点。** 使用本 skill 时：斯坦福监狱实验可以作为"情境力量存在"的定性例证，**不要引用其任何具体数字**（如"6 天崩溃""狱警行为比例"），也不要把它当作"随机角色必然压倒人格"的证据。更稳妥的定量证据是米尔格拉姆（有伯格 2009 年的部分重复）与阿希（有大量重复与变项研究）。
- 米尔格拉姆实验同样有时代问题：其伦理标准今天已不可复现（这也是它难以被完整重复的原因之一），"服从率"在不同年代与文化中的重做波动较大。
- 作者把"服从主要取决于情境变量而非人格变量"写得相当绝对，但基于米尔格拉姆档案的再分析显示参与者的事前态度与服从程度之间存在关联。这条结论应被降级为"人格的预测力远弱于我们的直觉"，而不是"人格完全无预测力"——不过这**不改变**行动结论：人格筛选依然不是有效的防御手段，改旋钮才是。
- 全书证据库以 WEIRD 样本（尤其美国大学生）为主，从众与服从的基线水平具有文化依赖性。在等级距离大或集体主义更强的语境中，规范性影响与服从的旋钮可能本来就拧得更紧，审计结果不能照搬美国基线。
- 书中"日常生活中的从众"一节援引的节能研究（描述性规范干预）属于单一现场研究，效应量与跨文化稳健性有限，做方案时应按"小样本 A/B 验证"处理，不要直接当标准答案铺开。

### 容易混淆的邻近方法论
- 与"企业文化建设 / 价值观宣导": 书中明确给出的反例是阿布格莱布式丑闻不是靠宣导能防的——斯坦福监狱实验里"没有人告诉参与者如何扮演角色"，角色是从既有社会经验里自动激活的。有效的是可审计的结构参数：谁下令、责任归谁、退出通道在哪。
- 与"头脑风暴 / 多开会": 作者指出群体讨论存在共享信息偏差——讨论倾向于集中在大家已经知道的信息上，只有某一个人知道的那些信息最可能被略过。所以"多开会"本身不是解药，先独立提交再汇总才是。
- 与"筛选好人 / 人格测评": 米尔格拉姆的 40 名精神病医生预测失败是这条路的直接反证（详见 `attribution-audit` 的 B 段）。
- 与"问责到人": 问责到人是对的，但要注意责任被切成碎片（"我只是协助执行"）恰恰是服从的加速器；责任归属必须同时配一个低成本的退出通道，否则拧的是另一个方向的旋钮。
