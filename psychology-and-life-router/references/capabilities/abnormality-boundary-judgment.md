# 心理异常判断的边界

## R — 原文 (Reading)

> "对所有的心理障碍来说，没有哪一条指标是必要条件。……同样，没有哪一条标准可以单独作为充分条件来区分异常的行为和正常的行为。正常和异常之间的差别，并不是两个独立行为类别之间的差异，而是一个人的行为在多大程度上合乎一整套公认的异常标准。"
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第14章 心理障碍 > 心理障碍的性质 > 确定什么是变态

---

## I — 方法论骨架 (Interpretation)

判断"某种状态算不算问题"时，禁止用单一指标（尤其禁止只用"违反规范"），必须按**七项指标逐项加权**，输出"在连续体上的位置"而非"是/否"：

1. 痛苦或功能不良；2. 适应不良（妨碍目标、扰乱他人）；3. 非理性；4. 不可预测/失去跨情境稳定；5. 非惯常性与统计极端；6. 令观察者不适；7. 违反道德或理想标准。

关键使用规则：
- **第⑤条陷阱**：统计罕见 ≠ 异常（超常智力也罕见但被赞许），必须结合"是否被社会赞许"。
- **第⑦条陷阱**：只用"违反规范"做判断，本质是在做道德判断而非临床判断。
- **没有任何一条是必要条件**（杀人后毫无内疚的人虽无主观痛苦，仍应标定异常），命中一项也不足以定性。
- **素质—压力交互论**：是"易感性 × 环境压力"两个乘数项，不是"先天 vs 后天"二选一；干预杠杆在可变的压力侧。
- **行为的意义由内容与情境共同决定**：同一行为在不同文化/情境含义不同；用"患有 X 的人"而非"XX 患者"的语言。

**本 skill 不提供任何诊断结论**，只提供"该不该、以及如何去寻求专业评估"的判断框架。

## A1 — 书中的应用 (Past Application)

### 案例 1: 罗森汉恩的假病人实验
- **问题**: 诊断标签会不会自我验证？
- **方法论的使用**: 8 个正常人仅凭伪装"幻觉"入院，入院后完全正常，仍无人识破，平均住院约三周。
- **结论**: 理性讨论→记"理智化"；记笔记→"书写行为"；出院诊断仍写"精神分裂症，但有所缓解"。
- **结果**: 标签一旦贴上，后续一切行为都被重新解释为症状——逻辑上不可推翻。

### 案例 2: 卡特赖特的"类躁狂"（诊断作为权力工具）
- **问题**: 诊断分类是否中性？
- **方法论的使用**: 1851 年卡特赖特受委员会委托，用"无可争议的科学证据"为奴隶制辩护，发明"类躁狂"（寻求自由的躁狂症，逃走的奴隶要被抓回治疗）。
- **结论**: 分类标准可以是权力工具。
- **结果**: 收到任何分类体系，先做利益审计——谁定义、谁受益、被分类者有无申诉渠道。

### 案例 3: 塞利格曼的习得性无助
- **问题**: 同样的打击为什么有人垮了？
- **方法论的使用**: 狗置于不可逃避电击后，即使放回可逃避情境也不尝试——"无济于事"的预期本身被习得。
- **结论**: 预期（而非现实）决定行为；干预要同时重置"做了会有用"的预期。
- **结果**: 抑郁被建模为同类预期状态，引出素质—压力与解释风格。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 读完 DSM 条目 / 心理科普，想对号入座判断自己或亲友"是不是有病"。
2. 看到他人某些行为，想下"他不正常 / 他有病"的结论。
3. 评估团队成员状态是否值得关注（绩效、出勤、情绪）。
4. 听到/看到任何人提及、暗示自杀。
5. 看到"某疗法改变了大脑""被压抑的记忆"类宣称。

### 语言信号（用户的话里出现这些就应激活）
- "他是不是抑郁 / 有心理疾病 / 不正常"
- "我是不是 XX 症 / ADHD / 双相"
- "这正常吗 / 我这样是不是有病"
- "他说不想活了 / 消失了也挺好"
- English: "is this a disorder", "self-diagnosis", "should I see a therapist", "suicide risk"

### 与相邻 skill 的区分
- 与 `expectation-and-label-engine` 的区别: 本 skill 处理"是否异常 / 诊断标签的边界"；expectation-and-label 处理"期望如何改变普通表现"。两者都警惕标签，但对象不同。
- 与 `stress-appraisal-coping` 的区别: 普通压力应对交给后者；一旦涉及"是不是障碍 / 自杀信号"，移交本 skill。
- 与 `neuro-genetic-claim-check` 的区别: 涉及"这是基因/大脑决定的"宣称时交给后者做证据解码。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **用七项指标逐项核对**
   - 完成标准: 列出七项并逐条评估；若只靠单条（尤其"违反规范"）下结论，显式指出这是道德判断而非状态判断。

2. **输出连续体位置，而非是/否**
   - 完成标准: 结论写成"在某条连续体上接近异常的程度"，并标注哪几条命中、是否结合社会赞许。

3. **涉及亲友/自己：只转介不诊断**
   - 完成标准: 用行为事实沟通（"这两周睡眠食欲有变化，要不要去聊聊专业的？"），**绝不**输出"你患有 XX"；提示"求助可以，诊断不行"。

4. **★ 涉及自杀信号：立即转介，不做分析**
   - 完成标准: 任何提及/暗示自杀，直接建议联系专业机构/危机热线/家人；不解读为"博关注"、不淡化、不单独承担、不承诺保密；可平静直接询问"你是在考虑伤害自己吗"（直接询问不增加风险）。
   - 判停条件: **一旦出现自杀信号，立即终止本 skill 的全部后续步骤（含第 5、6 步）**，只输出转介建议；不得继续做状态分析、不得输出任何诊断性表述。

5. **警惕标签自我实现**
   - 完成标准: 若已存在某定性，建议"先记录行为事实，再定期拿掉标签重看同一批事实"，避免先定性后取证。

6. **对疗法/脑科学宣称做反向推理检查**
   - 完成标准: 遇到"改变了大脑""被压抑的记忆"类宣称，追问行为指标是否真的改善、脑变化与机制是相关还是因果、记忆能否被独立证实。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **自行诊断**：作者明确警告"请读者抵制住诱惑，不要用本章所学的新知识判断你的朋友和家人是否有病"。本 skill 不给出任何诊断结论。
- **分析自杀信号**：涉及自杀表述，本 skill 只覆盖"识别与转介"，不做任何干预话术或原因分析——后者由专业人员执行。
- 用"统计罕见""违反规范"单独判定异常：这是道德/偏好判断，不是状态判断。

### 作者在书中警告的失败模式
- **诊断标签的自我实现**（CE42，罗森汉恩）: 标签贴上后，理性→"理智化"、笔记→"书写行为"、治愈→写进疾病叙事；逻辑不可推翻。
- **被压抑记忆可能被植入**（CE43）: 相信被压抑记忆的治疗师"鼓励发现 + 口头鼓励"= 完整塑造程序；治疗中恢复的记忆往往无独立证据。
- **"治疗改变了脑活动"≠ 解释了为何有效**（CE44，反向推理陷阱）: 从脑区变化反推机制需高度选择性对应，书中未建立；"有关"被写成"导致"是常见包装。
- **疗效研究的外部效度缺口**（CE45）: 研究排除共病、用理想化治疗师、只报完成者——"有效"结论的适用人群已被筛选过。

### 作者的盲点 / 时代局限
- 心理障碍的分类（DSM）与多数流行病学数据基于 WEIRD 样本，跨文化推广须谨慎。
- 书中部分经典研究（如罗森汉恩）后续受到方法论质疑，引用时标注"证据强度：有争议"，但不影响"标签会自我验证"这一核心警示。

### 容易混淆的邻近方法论
- 用"期望/标签如何改变普通表现"解释时交给 expectation-and-label-engine；用"这是基因/脑决定的"解释时交给 neuro-genetic-claim-check。
