# 记忆可信度评估

## R — 原文 (Reading)

> 即使在人们热切地希望说真话时，他们也有可能不能报告“真相”，所以研究者将注意力聚焦在目击证人记忆这个题目上。
>
> 她们的研究得出了一条一般性的结论：目击证人对于所看到信息的记忆很容易因事后信息而出现歪曲。
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第7章 记忆 > 作为重构过程的回忆 > 目击证人的记忆

---

## I — 方法论骨架 (Interpretation)

回忆不是从仓库里取出一盘录像，而是**用当下掌握的概括知识、图式与线索，把过去重建一遍**。重建必然带入三样东西：既有的知识结构、当下的状态与动机、以及事件之后流入的一切信息。所以"这段记忆可不可信"这个问题，要换成三个可操作的问题。

第一，**真诚度与准确度是两条独立的线**。一个人可以极度真诚、极度自信，同时错得很系统。作者的起点判断是：即便证人热切地希望说真话，他也可能报告不出真相。因此"他很确定""他没必要撒谎"这两句最常见的话，在评估里**权重为零**。书中 9·11 的纵向数据把这条钉死了：闪光灯记忆与日常记忆的衰退曲线完全重合，唯一稳定的差别是当事人对闪光灯记忆"相当自信"。

第二，**污染有三个通道，必须逐条查，不能合并处理**。
- 提问措辞污染：问"两辆车相撞时多快"估出 40+ 公里，问"接触时多快"估出 30；一周后再问影片里根本没有的碎玻璃，前组三分之一说看到了，后组只有 14%。一个动词改写了记忆本身。
- 事后信息污染：题目里塞进一个不存在的"让路标志"（原片是停车标志），正确再认率从 75% 掉到 41%。
- 共同目击者污染：严重事件后 86% 的目击者会与人讨论，与陌生人交流后有 29% 的人报告了来自同伴的信息，与朋友或情侣交流后高达 58%。**关系越近，传染越厉害**。而因此被排除采信的机会只有 14%。

第三，**评估的对象是流程，不是人**。既然提问本身就是一次干预，那么正确动作发生在提问之前：在任何人相互讨论之前逐人固定原始陈述，用中性措辞提问，优先采用日志、聊天记录、监控等外部记录。多个"独立证人"的一致证词，在有交流的条件下不是强证据，而是同一份被传染过的记忆的多次复述。

这套方法给出的判断不是"他撒谎了"，而是"这段叙述被污染的风险等级，以及据此该固定、隔离还是降权"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 洛夫特斯的目击证词系列实验
- **问题**: 司法体系需要知道，有什么办法能确保证人记忆的准确性；而研究者面对的前提是——真诚不等于准确。
- **方法论的使用**: 不改变事件本身，只改变**事后提问的一个词**，再看记忆报告如何随之改变。三组设计分别攻击三个通道：动词（相撞/接触）、预设（停止标志/让路标志）、社会传播（与共同目击者交流）。
- **结论**: 提问不是中性的测量工具，它本身就是一次干预；目击者的记忆"很容易因事后信息而出现歪曲"。
- **结果**: 一个动词让速度估计差出 10 公里以上，并凭空制造出未发生过的碎玻璃；一个错误的名词让再认正确率从 75% 掉到 41%；与亲近的人讨论后，污染率可达 58%。据此形成的取证规程是：先自由回忆，再开放提问，最后才问细节，且必须在讨论发生前单独固定。

### 案例 2: 9·11 闪光灯记忆的纵向追踪（Talarico & Rubin）
- **问题**: 那些极度生动、极度自信的"闪光灯记忆"，是不是比日常记忆更准确？
- **方法论的使用**: 在事件发生的**当场**取样——2001 年 9 月 12 日就记录下学生"听到消息时在哪里、和谁在一起"，同时记录他们前几天日常事件（晚会、比赛）的记忆做对照；然后在 1 周、6 周、32 周乃至 1 年后重测，比对一致与不一致细节的数目。只在事后问"记得多清楚"是无效设计。
- **结论**: 两类记忆的变化模式完全相同——一致细节以几乎相同的比率下降，不一致细节以几乎相同的比率上升。唯一的差别是信心。
- **结果**: 生动感与准确度被证明由不同机制产生，可以完全脱钩。作者因此写道：人们想把引起情绪反应的事件牢牢记住，"这就会使他们很难去想象，这些记忆有可能是不准确的"。

### 案例 3: 巴特利特的《幽灵的战争》与兔八哥握手实验
- **问题**: 回忆到底是在回放，还是在重建？如果是重建，它会往哪个方向偏？
- **方法论的使用**: 巴特利特让英国学生复述美国印第安传说《幽灵的战争》，观察偏误的**方向**；Braun 等人则反过来，用一则迪士尼广告去**写入**一段从未发生过的自传记忆。
- **结论**: 重构有三种可命名的扭曲——趋平（简化）、精锐化（突出并夸大某些细节）、同化（把细节改成更符合自己背景与知识的样子）。外部叙事可以整段写进自传记忆。
- **结果**: 独木舟被改成小船、抓海豹被改成钓鱼，超自然内容被删去；读过广告的人中 16% 声称自己在迪士尼乐园握过兔八哥的手，对照组只有 7%——而这些记忆全部不正确，因为兔八哥根本不是迪士尼的人物。判断标准因此明确：不要问"记得多清楚"，要问"这段记忆是在事件当时形成的，还是在后来某次叙述、广告或复盘中形成的"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 线上事故或安全事件的复盘会，几个当事人坐在一起"回忆一下当时发生了什么"，要写根因报告。
2. 绩效争议、客户投诉升级、劳动纠纷，双方各执一词地还原现场对话或操作步骤。
3. 设计用户访谈、问卷或调研提纲，题目里涉及"当时你是不是……""为什么你会……"这类回溯性提问。
4. 有人把"我记得清清楚楚""他亲眼看到的还能有错""我们几个都这么说"作为决定性证据——家庭争执、邻里纠纷、口述史料、历史叙述。
5. 自己怀疑"我到底做没做这件事"：定没定闹钟、发没发那封邮件、锁没锁门、吃没吃药——尤其是这件事被反复提醒过。

### 语言信号（用户的话里出现这些就应激活）
- "我记得很清楚，就像昨天发生的一样"
- "他亲眼看到的，还能有错吗？"
- "我们几个当时都在场，大家说的都一样"
- "我发誓我做过 / 我绝对没说过这句话"
- "回忆一下当时……""复盘一下当时……""口述一下"
- 英文: "I remember it clearly" / "I'm absolutely sure I did that" / "eyewitness testimony" / "vividly recall" / "we all remember it the same way"

### 与相邻 skill 的区分
- 与 `learning-engineering-pq4r` 的区别: 本 skill 是**审计**——评估一段已经存在的回忆能不能当证据（`memory-reliability-audit`）；后者是**工程**——如何让未来的记忆更牢、考试提取更顺（`learning-engineering-pq4r`）。"我记不住知识点"走 #5；"我记得的那个版本是不是真的"走 #4。两者唯一的接口是：编码特异性可以解释**为什么**某些细节提取不出来，但它提升的是细节数量，不提升准确度。
- 与 `judgment-bias-check` 的区别: #3 审的是**当下**的判断（这个估计是不是被锚定了、这个概率是不是被可得性扭曲了）；本 skill 审的是**过去**的经验叙述。话题是"我现在这个数字靠不靠谱"用 #3；"他当时是不是这么说的"用 #4。
- 与 `psych-claim-evidence-audit` 的区别: #1 审的是研究与数据层面的因果声称（操作性定义、对照基线、第三变量）；本 skill 审的是**个体经验叙述**。共同点只是"都要找独立记录"，但本 skill 独有的工具是三个污染通道与"自信不携带准确度信息"这条判据。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **确定用途与证据标准**
   - 明确这段回忆将被用来做什么：写复盘报告、定责、做产品决策、还是仅作线索。用途越重（定责、处分、诉讼），证据标准越高，对外部记录的依赖越强。
   - 完成标准: 已用一句话写下"这段回忆将支撑什么决定"以及该决定要求的证据等级（线索级 / 参考级 / 定责级）。

2. **把"真诚度"从证据清单里划掉**
   - 显式声明：当事人的自信程度、情绪强度、叙述流畅度、与你的关系，**一律不作为准确性的证据**。同时提示反复讲述会同时提高自信与污染机会。
   - 完成标准: 输出中已写明"以下评估不采用自信度、生动度、真诚度作为判据"，且没有出现"他很确定所以……"这类推论。
   - 判停条件: 若该回忆属于创伤记忆、可能涉及司法程序或当事人有认知/脑损伤史，停止自行评估，转介专业人士并说明原因（见 B 段）。

3. **还原时间线与复述史**
   - 记录四个时间点：事件发生时刻、第一次被记录/陈述的时刻、当前陈述时刻、中间被复述过多少次（尤其是否在群体场合复述过）。
   - 完成标准: 已列出"事件 → 首次记录"的间隔天数，以及复述次数与复述场合的清单；若首次记录在事件后 48 小时之外，标记为高污染风险。

4. **逐条查三个污染通道**
   - 措辞污染：此前所有关于此事的提问里，有没有带预设的动词、名词、形容词（"撞得有多快""是不是因为缓存没刷新才崩的"）？
   - 事后信息污染：当事人在形成陈述前，接触过哪些外部描述（群聊结论、他人猜测、媒体报道、监控回放、别人的复盘稿）？
   - 共同目击者污染：多个陈述人之间是否交流过？是什么关系（陌生人 / 同事 / 朋友 / 伴侣）？
   - 完成标准: 三个通道各自给出"未污染 / 可疑 / 已确认污染"的判定，每条判定附一句依据；已确认污染者进入下一步降权。

5. **找外部记录并做交叉比对**
   - 逐项列出可用的独立记录：系统日志、时间戳、聊天与邮件、监控、工单、提交记录、体检数据、当时的照片。用外部记录覆盖回忆中的**关键争点**（不是所有细节）。
   - 完成标准: 每个关键争点旁标注"有独立记录佐证 / 有独立记录反证 / 无任何记录"；反证项已在结论中明确指出回忆有误。
   - 判停条件: 若关键争点全部有独立记录，直接以记录为准，跳过可信度评级，只输出"回忆与记录的分歧点"。

6. **出具可信度评级与处置建议**
   - 给出三档结论：**可用**（无污染通道、有记录佐证）/ **降权使用**（存在可疑通道，仅作线索，须其他证据补强）/ **不可用作证据**（已确认污染，或与记录反证）。
   - 针对流程给出一条可执行的改进：隔离询问、先自由回忆再问细节、事发当场固定陈述、把"大家一起回忆"改成逐人书面提交。
   - 完成标准: 输出中包含（a）每个陈述人或每段记忆的评级，（b）至少一条具体的流程修改建议，（c）明确写出"多个证人一致"在本例中是否构成独立印证。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **创伤记忆、虐待、性侵、司法程序中的证人评估**：本 skill 只处理"回忆作为信息源的技术可信度"，不处理创伤对记忆编码的复杂影响，也不能替代司法与临床的专业规程。遇到这类场景应转介并说明边界。
- **回忆内容可以完全由外部记录覆盖时**：不需要评估记忆，直接查记录。对记忆做可信度评级反而会给一个本可确定的事实引入不必要的怀疑或背书。
- **判断的对象是当下的知觉或当下的判断，而非过去的记忆**：那是 `judgment-bias-check` 的领域。
- **对认知障碍、脑损伤、酒精/药物影响下的陈述做"技术性"评估**：这类情况需要先做医学判断，套用污染通道会得出误导性结论。

### 作者在书中警告的失败模式
- **闪光灯记忆（CE24）**——failure_mode：记得最清楚、最自信的那些记忆，并不比日常记忆更准确。mechanism：生动度来自情绪唤起时的编码强度与反复复述，准确度来自编码时的注意质量与提取时的线索匹配，二者由不同机制产生、可以完全脱钩；更糟的是，反复讲述既提升生动度与信心，又**增加被重构污染的机会**——每复述一次，就多一次用当前图式重写细节的机会。"我记得清清楚楚"这个动作，同时提高自信、降低准确度。
- **错误信息效应（CE25）**——failure_mode：提问的措辞改写记忆本身，一个动词改变速度估计并凭空制造出未发生过的细节。mechanism：重构时系统把原始痕迹与事后信息混合，而来源监控不能可靠区分"我看到的"与"我后来听说的"；提问措辞之所以特别危险，是因为它同时满足三个条件——来自权威（提问者）、时间上紧跟编码、内容与原始场景同属一个图式。**提问不是中性的测量工具，它本身就是一次干预。**
- **共同目击者污染（CE26）**——failure_mode：多个"独立证人"的一致证词，可能只是同一份被传染过的记忆的多次复述；关系越近传染率越高（陌生人 29%，朋友或情侣 58%），而因此被排除采信的机会只有 14%。mechanism：社会分享本身即复述（强化的是叙述版本而非原始痕迹）+ 亲密关系降低来源监控的警觉性（共享现实本就是亲密关系的功能）+ 一致性压力推动冲突双方收敛到同一版本。于是"多源印证"在有交流的条件下被系统性高估。
- **想象膨胀（CE27）**——failure_mode：反复想象的事会被记成自己做过的事。mechanism：想象生成与真实感知高度相似的知觉细节与情节结构，而来源监控依赖"这条痕迹带不带知觉标签"这类启发式；想象次数越多痕迹越流畅，提取流畅度又被当作"真发生过"的证据，形成正反馈。推论：**在高频提醒的场景下，靠"我记得我做过"判断事务是否完成是系统性不可靠的**，必须用外化的执行记录取代提醒。

### 作者的盲点 / 时代局限
- **可重复性危机**：本书英文版成书于 2014 年，早于 2015 年开放科学协作（Open Science Collaboration）的大规模重复验证。书中被当作定论呈现的部分效应——社会启动、自我损耗（ego depletion）、部分具身认知、面部反馈假说的强版本、权力姿势——在 2015 年后大面积重复失败。本 skill 依赖的洛夫特斯错误信息效应与闪光灯记忆纵向研究，属于重复记录相对稳健的一类，但**效应量应被理解为实验室条件下的估计**；下游引用时须标注证据强度，不得当作法庭级确定结论。
- **生态效度被默认成立**：洛夫特斯范式的材料是简短的车祸影片与幻灯片，真实目击事件在情绪强度、持续时间、个人利害关系上完全不同——实验室得到的污染率不能外推为具体案件中的错误率。
- **WEIRD 样本**：本书引用研究的样本绝大多数来自西方、受教育、工业化、富裕、民主社会（尤其美国大学生）。记忆的社会传播方式、权威对提问措辞的放大效应，在权力距离不同的文化里可能显著不同。
- **对"重构"的 normative 态度偏乐观**：作者把扭曲当作正常加工的副产品（"对于事件要点的重构已经可以使我们很好地应付日常生活了"）。这在多数日常场景成立，但当记忆被用于定责、处分或历史叙述时，"够用"不等于"可信"——本 skill 正是把这条乐观限定在它该在的地方。

### 容易混淆的邻近方法论
- **"追问更多细节可以提高准确度"** —— 错。追问会**增加**污染机会。正确的顺序是先取自由回忆、再开放提问、最后才问细节。
- **"复现当时的背景能帮助回忆，所以能提高准确度"** —— 错。编码特异性（第7章）说的是背景匹配能提升**提取成功率**（潜水员在海滩学就在海滩测得更好；学习与回忆时同气味，四周后成绩更好），但提取更顺带来的是更多细节和更高自信，**不是更高准确度**。用于取证时必须注明这一点。
- **"多个独立来源一致 = 真"** —— 只在来源确实独立（未交流、未接触同一二手描述）时成立。这是共同目击者污染这一条要拦的直觉。
- **"记忆不可信"** —— 本 skill 的结论不是这个。准确表述是：**细节不可信、自信不可信**；要点（gist）层面的记忆在日常场景中通常是可用的。把结论推到"记忆全不可信"会让人在无外部记录可用时失去唯一的线索来源。
