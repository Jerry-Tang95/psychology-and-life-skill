# 研究与因果声称审查

## R — 原文 (Reading)

> 高相关只是表明这两组数据以一种系统的方式建立了联系，相关并不意味着一个事件可以导致另一个事件的发生，相关并不意味着因果关系。相关可能反映了几种因果可能性中的一种，也可能根本就不反映因果关系。许多可能性涉及第三变量，这个变量在背后造成了它们的相关。
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第2章 心理学的研究方法 > 相关法

---

## I — 方法论骨架 (Interpretation)

这是一套给"声称"做体检的程序，对象是别人（或你自己）递过来的任何一条"A 造成了 B"。它不问"这个说法有没有道理"，只问四件事，按固定顺序过：

**第一关，概念落地。** 把声称里所有抽象词换成"我打算用哪个具体操作来测它"。换不出来，这个词就不可检验，争论没有裁判，可以直接停。这一步顺带消灭大量伪分歧——双方常常在说两个不同的东西。

**第二关，把共变改写成三个因果故事。** 观察到 A 与 B 一起变，同一个数据在逻辑上至少对应三种结构：A→B、B→A、以及某个第三变量 C 同时推动两者。必须把三条都写成具体的、有名有姓的故事（不许写"可能还有其他因素"），然后逐个问"什么观察能把它们区分开"。答不出区分性证据，结论只能写成"A 与 B 共变"。

**第三关，追问对照基线。** 听到"提升了 X%"，先问"对照组提升多少"。没有对照条件的改善，等于零信息——练习效应、自然缓解、被关注感都能造成同样的曲线。三重基线值得记住：不治也会好的自然缓解基线、预期会好的安慰剂基线、以及"多数研究都这样吗"的元分析基线。

**第四关，清点控制程序。** 恒定、随机分配、双盲、安慰剂，四件工具各杀一类备选解释。逐条打勾后，剩下的不是"我支持这个结论的理由"，而是"还没被杀掉的备选解释清单"。假设的可信度是这份清单长度的减函数——每多一条站得住的备选，就把信心往下调一档，不用等它被推翻。

最后加一条利益检查：解释恰好对提出者有利、复杂问题配单一原因、用个人观点取代证据且不接受批评，三条任一命中，怀疑等级上调。输出不是"对/错"，而是三选一的分级：**可用证据 / 待验证 / 仅作参考**，并附上一句"补哪一项证据成本最低"。

## A1 — 书中的应用 (Past Application)

### 案例 1: 阈下自助磁带实验（Greenwald 等，237 人）
- **问题**: 市场上卖的"阈下自助磁带"宣称能在你听不见的音量下改善自尊或记忆力。怎么判断它到底有没有效？
- **方法论的使用**: 研究者不满足于测"有没有效"，而是预先假设安慰剂效应一定存在，于是把它设计成一个自变量：前测（标准化自尊与记忆测验）→ 237 名 18–60 岁参与者随机分配到"记忆磁带"或"自尊磁带"→ 听 5 周 → 后测，且研究者不知道谁拿了哪种（盲法）。最精妙的一步是**错贴标签**：把记忆磁带装进标着"自尊"的盒子，反之亦然。
- **结论**: 改善完全由"参与者以为自己拿的是哪种磁带"预测，与磁带实际内容无关。作者的判词是"省下你的钱吧"。
- **结果**: 客观自尊与记忆测量**零改善**；主观改善幅度却很大，且跟随标签而非内容。整个效应是预期造成的。

### 案例 2: 蒙斯特博格的记者们（同一场演讲，立场决定你"看到"什么）
- **问题**: 20 世纪初，蒙斯特博格给一大群记者做和平演讲，事后各家报道在最基本的物理事实上互相矛盾——鸦雀无声 vs 持续鼓掌，一直微笑 vs 严肃无笑容，脸涨得紫红 vs 脸变得惨白。谁在撒谎？
- **方法论的使用**: 作者不追问谁撒谎，而是把每篇报道与记者的**政治立场**对照。同时给出了补救工具：标准化（统一观察程序）+ 操作性定义（统一概念边界），并且找一个与结果无利害关系的第三方评分者做基线。
- **结论**: 观察者偏见是动机与预期的系统性产物，不是个别人不严谨。偏见发生在注意与编码层面，被过滤掉的东西从未进入意识，所以"更仔细地看"补不回来。
- **结果**: 连"有没有鼓掌"这类肉眼可见的事实都被立场扭曲。同类机制在 125 对已婚夫妇身上复现——双方对同一段对话的评分都偏离中立基线，且偏离方向由"他们对这段关系有多大信心"预测。推论很硬：**多找几个证人无效，偏见同向时人数只会放大错误的可信度。**

### 案例 3: CEO 长相与公司业绩（Rule & Ambady）
- **问题**: 收集《财富》500 强排名前 25 与末 25 名公司的 CEO 照片，50 名学生在 7 点量表上评"这人领导公司会有多优秀"，再与各公司业绩对照。结果显示领导力评分与公司赢利正相关。能说"长得好就能当赢利公司的 CEO"吗？
- **方法论的使用**: 研究者把"正相关"拆成至少两条相反的因果路径（是公司挑了某种长相的人，还是这种长相带来了成功），并且明确说明为什么只能用相关法——你既不能随机分配"人长什么样"，也不能随机分配"公司是否赢利"。
- **结论**: 在无随机分配的情况下，拒绝使用因果语言。
- **结果**: 论文原话保留为"当然，我们不能得出因果的推断"。这个案例的价值在于示范**研究者的克制**：拿到了显著的正相关，仍然停在相关。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 读到"研究表明 X 的人更容易 Y"，正准备据此改自己的行为或改一个产品/制度。
2. 供应商 / 咨询方 / 内部团队给出一个"用了我们的方案提升了 X%"的效果声明，要看它能不能进决策证据链。
3. 一次 A/B 测试或试点结束，团队准备宣布胜利，需要清点还有什么备选解释没被杀掉。
4. 复盘会上两方对"到底是什么导致了这个结果"各执一词，且争论已经开始各说各话。
5. 听到"科学已经证明……""专家说……"，需要判断这句话的信息含量。

### 语言信号（用户的话里出现这些就应激活）
- "研究显示 / 研究表明 / 有数据表明……"
- "X 的人更容易 Y / A 和 B 高度相关"
- "用了之后提升了 X%""90% 的人觉得有帮助"
- "这说明是 A 导致的""所以只要做 A 就能解决 B"
- 英文: "studies show" / "is linked to" / "causes" / "is associated with" / "proven by science"

### 与相邻 skill 的区分
- 与 `number-and-measurement-defense` 的区别: 本 skill 管**因果结构**——有没有对照组、有没有第三变量、控制程序做没做。那个 skill 管**数字与分数本身**——这个指标信不信、效度如何、离散性与呈现形式有没有骗人。先跑本 skill 确定"这条声称是什么结构"，再跑那个 skill 审它给出的数字。
- 与 `problem-representation-and-falsification` 的区别: 那个管**自己的假设**——怎么把它形式化成可被推翻的预测、怎么主动去找反驳证据（沃森选择任务、问题空间三要素）。本 skill 管**外部递过来的声称**的验收。当问题是"我该怎么证明自己错了"，用那个；当问题是"他这句话凭什么成立"，用本 skill。
- 与 `neuro-genetic-claim-check` 的区别: 那个专管"这是遗传的 / 大脑决定的"这一类**科学背书话术**的失真路径。本 skill 是通用审查器，不管证据类型。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **把声称拆成变量，并给每个抽象词下操作性定义**
   - 完成标准: 声称中出现的每个抽象概念都写下了"用哪个具体操作来测它"；若至少一个概念无法操作化，则把它标为"不可检验"并停止后续因果讨论。
   - 判停条件: 若对方无法给出任何关键术语的测量操作 → 直接输出"该争论没有裁判，建议各自保留意见"，跳到步骤 6。

2. **把"共变"改写成三个有名有姓的因果故事**
   - 完成标准: 已写出 A→B、B→A、C→A 且 C→B 三条，第三变量 C 必须被具体命名（不接受"可能有其他因素"），并为每条写出"什么观察能把它们区分开"。
   - 判停条件: 若声称来自随机分配且操纵了自变量的真实验 → 可省略 B→A，直接进入步骤 4。

3. **追问对照基线："和什么比？"**
   - 完成标准: 找到了对照组 / 基线期的具体数值，或明确确认不存在对照。
   - 判停条件: 若对方给不出任何对照基础 → 输出"该效果声明无对照基础，结论当场作废"，跳到步骤 6。

4. **清点控制程序，列出残留的备选解释清单**
   - 完成标准: 对恒定法、随机分配、双盲、安慰剂四项逐条打勾（做了/没做/不可行），并输出一份"未被杀掉的备选解释"清单，每条注明它会被哪一项控制程序杀死。

5. **查利益与简单性**
   - 完成标准: 三问全部回答——(a) 这条解释是否恰好对提出者有利？(b) 是不是复杂问题配了简单答案、复杂效应配了单一原因？(c) 提出者是否用个人观点取代证据且不接受批评？任一命中即上调怀疑等级。

6. **输出分级结论**
   - 完成标准: 给出"可用证据 / 待验证 / 仅作参考"三选一，并附：(a) 支撑该分级的遗漏项清单；(b) "补哪一项证据成本最低"的一条具体建议；(c) 若结论被采信，一个可被日后检验的预测（含时点与幅度）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **纯事实查询或信息检索**（"这个术语什么意思""这份数据在哪里"）——没有声称需要审查，套用只会制造噪音。
- **已有随机对照、且被独立第三方重复的成熟结论**——四关早已走过，重跑一遍是形式主义。
- **道德、法律、审美、价值判断**——"应不应该做"不是因果声称，本 skill 的证据标准在这里不适用。
- **需要的是对一段具体记忆的可信度评估**（目击证词、闪光灯记忆）→ 转 `memory-reliability-audit`。

### 作者在书中警告的失败模式
- **把相关当因果（CE01）**: failure_mode 是看到 A 与 B 共变就宣布 A→B 并据此设计干预；mechanism 是相关只是共变的统计描述，不携带方向信息，而人的知觉系统天生寻找"一个原因解释一组现象"，叙事一旦生成就被当成解释。warning_signs：证据链里没有一个变量是你主动操纵的；还没列出 B→A 就下了结论；结论恰好支持你或资助方的立场。
- **观察者偏见（CE03）**: failure_mode 是两个信源看同一件事得出相反的"事实"，且双方都真诚地认为自己只是如实记录；mechanism 是过滤发生在注意与编码阶段，被过滤掉的东西从未进入意识，因此无法靠"更仔细"补回，也解释了为什么多找证人无效。
- **期望效应（CE04）**: failure_mode 是实施者"知道"哪组被寄予厚望，于是无意识地多给一点提示，最后那组真的更好；mechanism 是期望经微行为通路（语气、等待时长、反馈频率）在意识之外传递，所以**对意图免疫**——好意和恶意一样污染结果，且实施者越认真，污染越大。
- **安慰剂效应（CE05）**: failure_mode 是客观指标零改善而主观报告"明显好转"；mechanism 是改变来自"对介入的信念"而非介入本身，且"意识到自己被测量"本身就是第二条通路。书中量级警告：无疗效药物也能让 70% 的使用者报告良好或极好效果。推论：**任何"用了都说好"的自评式效果证明，信息量接近零。**
- **阈下影响的神话（CE06）**: failure_mode 是一个被严格实验推翻的说法仍在收割信念与钱包；mechanism 是三层叠加——"已被证伪"没有传播渠道而原始骗局有利润驱动、说法符合直觉故事自带传播力、教育程度越高反而越信（反向相关）。
- **媒体标题三步失真（CE12）**: failure_mode 是"科学家发现冲动基因"式的标题把多基因说成单基因、把远端可能后果说成近端机制、把推测说成因果；mechanism 是标题生产的经济激励是简洁与冲击，而科学结论的本质是条件与限定，落差由三处填充。

### 作者的盲点 / 时代局限
- **本书英文版成书于 2014 年，早于 2015 年可重复性危机的大规模重复验证。** 书中被当作定论呈现的若干效应（社会启动、自我损耗、具身认知的部分经典实验、面部反馈假说的强版本、权力姿势）在 2015 年后大面积重复失败。**因此：本 skill 在书中取材时，凡引用 2014 年前的单一实验结论，须标注"证据强度：弱/有争议"，不得当作已证事实。**
- **用本书第2章的标准去查本书自身，会有相当一部分"探索研究"降级为初步证据。** 这不是作者的疏忽，是时代的边界。
- **斯坦福监狱实验**（本书作者津巴多本人的成名作）在 2018 年后被档案研究严重质疑（需求特征、实验者介入、样本自选择），书中仍以正面经典呈现——这是作者最明显的自利盲点。
- **外部效度被默认成立**：书中大量实验室因果结论被直接外推到真实生活，而"控制越严、行为越不像自然行为"这一权衡作者只在第2章一笔带过。
- **WEIRD 样本**：全书绝大多数研究样本仍是西方、受教育、工业化、富裕、民主社会（尤其美国大学生），作者自己承认但未真正修正证据库。

### 容易混淆的邻近方法论
- **"备选解释排查" vs "证伪"**：前者是清单式地枚举还能怎么解释同一结果（降低信心），后者是事先写下"什么观察会让我放弃它"（设定拒绝条件）。两者互补，不要互相替代。
- **随机取样 vs 随机分配**：随机**取样**解决对外能不能推广（样本代表总体），随机**分配**解决内部能不能推因果（打散个体差异）。一篇报告做了其中一个，不代表做了另一个。
- **"信度"不是"证据强度"**：一个测量非常稳定不代表它测对了东西，也不代表基于它的因果声称成立。
