# 说服抵御与顺从设计

## R — 原文 (Reading)

> "中心路径指的是这样的情形：人们仔细思考说服性的沟通意见，因此态度改变与否取决于论点的强弱。外周路径指的是这样一些情形：人们不怎么集中精力关注信息，而是对情境中的表面线索做出反应。"
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第16章 社会心理学 > 态度、态度改变与行动 > 说服过程

---

## I — 方法论骨架 (Interpretation)

说服不是"把话说漂亮"，而是**先判断对方在用什么系统处理信息，再决定力气花在哪**：

- **中心路径（高精细化）**：对方有动机且有能力认真想，态度改变取决于**论点强弱**。若论据薄弱，唤醒对方的精细化反而帮倒忙。
- **外周路径（低精细化）**：对方没在认真听，态度被**表面线索**驱动——权威、名人、包装、情绪、精美度。

在此之上叠加两类"顺从技术"：
- **登门槛（小→大）**：先求一个几乎不会被拒的小承诺，再提大请求；燃料是**自我形象一致性**，且**绝不能为第一个小承诺付钱**——给钱会把首个行为归因为外部，掐断后续效果。
- **以退为进（大→小）**：先提明知会被拒的大请求，再提真想要的小请求；燃料是**互惠**。
- **认知失调**：想让人真正**内化**一件事，给的外部理由要刚好够启动行为、但不够让他解释自己为什么做；给太多钱或表扬会阻断内化。

一个容易被忽视的反向杠杆：**单纯测量就能改变行为**——寄一份态度问卷，6 个月后实验组多出 8.6% 的人登记献血。所以"让他表态"本身就是干预手段。

本 skill 的兵法是双刃的：既能设计正当请求，也能在被人套用时识别出来。

## A1 — 书中的应用 (Past Application)

### 案例 1: 费斯廷格 1 美元 vs 20 美元撒谎实验
- **问题**: 怎样的外部报酬能让人真心觉得一件无聊的事"好玩"？
- **方法论的使用**: 斯坦福学生做完无聊活动后被请求撒谎说"挺好玩"，一组得 20 美元、一组得 1 美元。
- **结论**: 20 美元组外部理由充足 → 无失调 → 态度不变（"为了钱"）；1 美元组外部理由不足 → 强失调 → 改变态度合理化（"这真的挺好玩"）。
- **结果**: 1 美元组真的觉得活动有趣，20 美元组没有。反直觉（常识以为钱越多态度越正）被实验证实。

### 案例 2: 布莱尔态度调查（测量本身改变态度）
- **问题**: 问卷能不能只当作测量工具？
- **方法论的使用**: 先问"你对英国政治多感兴趣"，再让受访者分别列出布莱尔的 2 个 / 5 个优点或缺点，最后评喜爱度。
- **结论**: 对政治低兴趣者，负面清单越长（提取越费劲），评价反而越好——"如果我连他五个缺点都想不出，他可能真不错"。
- **结果**: 效应只出现在低兴趣者身上；高兴趣者不受影响。说明**任何测量都可能是干预**，且结论须给出"在谁身上不成立"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 要推动另一个团队 / 客户接受一个方案、提案或改造。
2. 发现自己"莫名其妙"同意了某件事，想复盘是不是被套路了。
3. 要写一封说服邮件 / 提案 / 营销文案，不确定该堆论据还是堆信任背书。
4. 需要让同事答应一个耗时请求（如数据治理、跨部门协作）。
5. 用问卷 / 访谈预测用户"会不会买 / 会不会用"，据此排需求优先级。

### 语言信号（用户的话里出现这些就应激活）
- "怎么才能让 X 同意 / 接受 / 配合"
- "我感觉被洗脑 / 被带节奏 / 被营销了"
- "登门槛 / 互惠 / 认知失调 / 外周路径"
- "用户说愿意付费，这能信吗"
- English: "how do I persuade them", "foot-in-the-door", "resist this pitch", "attitude predicts behavior?"

### 与相邻 skill 的区分
- 与 `situational-force-audit` 的区别: 本 skill 是**一对一或一对多的说服技术**（你主动设计信息或请求）；situational-force-audit 是**群体结构性力量**（从众规范、权威服从、群体极化），你不设计，只是审计它。
- 与 `expectation-and-label-engine` 的区别: 本 skill 改变的是**对方的态度与单次行为**；expectation-and-label 改变的是**被预期者长期的自我形象与表现**。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **判定对方走哪条路径**
   - 完成标准: 能明确回答"对方有动机且有能力认真想这件事吗？"——高动机高能力→中心路径；否则→外周路径。

2. **若中心路径：做扎实论据**
   - 完成标准: 论点有依据、留出提问 / 反驳时间；若自身论据薄弱，**不要**去唤醒对方精细化（改用外周线索或先补证据）。

3. **若外周路径：用线索而非论据**
   - 完成标准: 输出简短、有权威背书 / 可视化 / 情绪锚点的一页纸，不指望对方逐条推敲。

4. **设计请求序列（拿到正当答应）**
   - 完成标准: 选定登门槛（小承诺，**给身份不给钱**，强调"你是这方面最懂的人"）或以退为进（大→小，靠互惠）；判停条件：若对方把首个行为归因为金钱或被迫，则登门槛失效，须换路径。

5. **推动内化：给最少必要外部理由**
   - 完成标准: 报酬 / 表扬只够启动行为，不足以解释行为；若目标是态度改变而非合规，避免"每次达标奖励 N 元"。

6. **想动行为：先让人表态**
   - 完成标准: 在征集行动前先要一次公开表态（如公开投票、留言承诺），利用"单纯测量改变行为"效应提升后续转化。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **操纵、欺骗或利用他人认知弱点牟利**——本 skill 只用于正当说服与自我防御，不用于套路别人掏钱 / 让步。
- 对方处于无法自主决策的状态（未成年人、危急、明显被胁迫）时，不对其使用顺从技术。
- 纯信息传递（只是通知，不求态度或行为改变）不需要本 skill。

### 作者在书中警告的失败模式
- **登门槛给钱就失效**: 若首个小承诺被归因于外部报酬，"我是支持环保的人"这种自我形象不成立，后续大请求崩塌（来自 P45 / CE 相关条目）。
- **认知失调的文化边界**: 失调发生在"自我概念"层面，独立型自我在自己的选择上体验更多失调，相互依赖型自我在朋友的选择上体验更多——西方样本结论不能直接套。
- **抵御说服消耗资源**: 先做一个高自控任务（如"不要想白熊"）后，人更容易被薄弱论据说服；"不被说服"是消耗性资源，不是稳定人格。

### 作者的盲点 / 时代局限
- 本书英文版成书于 2014 年，早于 2015 年可重复性危机。上一条"白熊任务 / 自我损耗"家族效应在后续重复中强度存疑，引用时标注"证据强度：有争议"。
- 精细可能性模型本身稳健，但书中所举的若干"外周线索"实例多来自 WEIRD（西方、受教育、工业化、富裕、民主）样本。

### 容易混淆的邻近方法论
- 与 `situational-force-audit`：群体从众 / 服从是结构性情境力量；本 skill 是你主动设计的说服信息。
- 与 `expectation-and-label-engine`：标签改变长期自我形象；本 skill 改变单次态度与行为。
