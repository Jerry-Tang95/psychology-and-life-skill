# 数字、统计与测量分数审查

## R — 原文 (Reading)

> 测验和实验可能是可靠的，但可能却是无效的。例如，我们把鞋子的大小作为幸福感的指标。这是可靠的（我们总能得到相同的答案），但这一指标是无效的（我们无法得知你每天的幸福水平）。
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第2章 心理学的研究方法 > 心理测量（获得信度和效度）

---

## I — 方法论骨架 (Interpretation)

拿到任何一个数字或分数，在让它影响决定之前，按固定顺序过两道闸：**测量四道门**（审分数）和**数字五关**（审统计量），最后补一道**呈现形式审计**与一条**高利害回路检查**。

**测量四道门**，顺序不能颠倒：
1. **信度**——重复测是否给一致结果。信度是"跟自己"相关的属性，它只是门槛，不是证明。
2. **效度**——先问"**对什么目的**有效"，再分三型查：内容效度（覆盖欲测领域的全部方面了吗）、效标效度（能预测一个外部标准吗）、结构效度（真的测到那个构念吗，且与该构念之外的东西无关吗）。
3. **常模**——裸分数没有意义，我的分数是跟谁比的？那个群体和我可比吗？
4. **标准化**——我拿到分数时的施测条件（指导语、时限、能否查资料、有没有人监考）与常模建立时一致吗？

核心不等式要背下来：**可靠 ≠ 有效**。由此推出两条不对称结论——**不可信必然无效**（第一步不过，后三步不必查）；但**可信完全可能无效**（鞋码反复量都是同一个数，却完全不反映幸福感；成年身高测智力同理，极其稳定却测的不是智力）。所以看到"该指标非常稳定/可复现"的宣传，不能推出"该指标有意义"。

**数字五关**：① 样本多大？② 报了离散性度量吗（只给平均数的要警惕）？③ 显著性水平是多少（没报 p 值的"显著差异"等于没说）？④ 测量工具真的测到了它声称在测的东西吗？⑤ 中数、众数、平均数是否一致？三者分歧大说明分布有偏或存在极端值，此时以中数为准。五关全过才当"可用证据"，任一缺失降级为"待验证"。

**呈现形式审计**：同一个数字用频率形式（100 中的 10）比百分比（10%）更容易唤起具体画面，让人觉得风险更高。看到数据先换算成另一种等价形式再感受一次——两次感受不一致，说明形式在操纵你。

**高利害回路**：一旦分数被用来分配资源（分班、晋升、授信、推荐位），测量就不再是中性的，它变成了干预。分数会通过资源通路、他人期望通路、自我概念通路改变被测量者的实际处境，使最初的分数自我兑现。此时必须按"干预"而非"测量"来评估它。

## A1 — 书中的应用 (Past Application)

### 案例 1: 琼斯先生的暴力风险评估（100 中的 10% vs 100 中的 10）
- **问题**: 你是一名临床心理学家，要判断一位出院病人是高风险、中风险还是低风险。拿到的 material 写着"每 100 名与琼斯先生相似的病人中，预计其中 10% 的病人会在出院头几个月内做出暴力行为"。这个数字该怎么读？
- **方法论的使用**: 把数学上完全等价的两种表述（"100 中的 10%" 与 "100 中的 10"）分给两组职业心理学家，比较评级差异——这是一次干净的呈现形式审计。
- **结论**: 呈现形式改变了高后果判断。频率形式（100 中的 10）因为极易形成"一间屋子里有 10 个危险的人"的心理画面，让人显著更保守。
- **结果**: 30.3% 拿到"10%"版本的人评为低风险，而拿到"100 中的 10"版本的人只有 19.4% 评为低风险——赌注是一个人的自由。
- **同题的第二层发现**: 把参与者按算术能力分组后，低算术能力组对两个版本给出了极为不同的风险评分，高算术能力组给出了几乎一样的评分。这是书中**唯一自带解药的偏差**：数字素养的作用是把不同表面形式换算成同一个内部表征，具备这个能力的人不会被呈现形式操纵。推论——补统计课是真实有效的防御措施。

### 案例 2: 网络 IQ 测验的四个分数
- **问题**: 波因德克斯特在同一个网站、同一天做了 4 个"测同一能力"的 IQ 测验，得分分别是 116、117、129、130。他兴冲冲地只记得自己最好的一次：159 分。这些数字可信吗？
- **方法论的使用**: 按不可信必然无效的规则，先查信度——同一工具重复测，结果差得足以改变分类（从"较好"跨到"优秀或非常优秀"的边界），信度即不成立，后面三步无需再查。再查常模：在线得分是跟"愿意来做这个测验的人"比较的，没有理由相信这批人的均值是 100。
- **结论**: "如果测验不是可信的，那么它们就不是有效的"——这是一条可以套用到任何在线测评、性格测试、能力评估产品上的判据。
- **结果**: 判定该测量工具不可信，因而无效；且当事人只引用最好那一次成绩（选择性记忆），进一步放大了失真。

### 案例 3: 用"实际值 − 预期值"的差值控制基线（Walton & Cohen 归因干预）
- **问题**: 一个极轻的干预（让学生读到"多数高年级学生都曾担心是否被接纳"）之后，怎么证明实验组真的变好了？两组学生的第一学期成绩本来就不一样。
- **方法论的使用**: 不用绝对成绩做比较，而用"实际成绩 − 根据第一学期成绩推得的预期成绩"的**差值**作为因变量。这一招把基线差异这个混淆变量在测量层面直接消掉——每个人跟自己的预期比，而不是跟别人的绝对值比。
- **结论**: 差值指标让"干预有效"这个声称有了可判定的量纲，且不需要大样本去抵消基线不齐。
- **结果**: 实验组实际成绩高于由其历史成绩推得的预期，控制组低于预期——只改归因、不改任何实质能力，成绩就变了。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 收到一份测评/考试/绩效考核分数，准备据此做出分流、晋升、淘汰或自我判断。
2. 看到"平均提升 X%""N% 的用户认为"这类带数字的效果声明，要判断它能不能进入决策。
3. 一份报告给了平均数但没给分布，有人据此宣称"整体情况不严重/很好"。
4. 看到"统计显著""p<0.05"的结论，需要判断它是否值得据此行动。
5. 公司准备上线一套评分体系（潜力评分、信用分、绩效排名、内容推荐权重），需要审计它会不会反噬。

### 语言信号（用户的话里出现这些就应激活）
- "平均 / 均值 / 一般来说""提升了 X%""N% 的人认为"
- "我的得分是 XX""这个测评说我……""这个指标很稳定/可复现"
- "p<0.05""统计显著""边缘显著""呈现出……的趋势"
- "这个报告没给样本量""没说标准差""只给了平均值"
- 英文: "on average" / "statistically significant" / "my score is" / "a reliable measure" / "X percent of"

### 与相邻 skill 的区分
- 与 `psych-claim-evidence-audit` 的区别: 那个管**因果结构**（有没有对照组、有没有第三变量、控制程序做没做）；本 skill 管**数字与分数本身**（信不信、效度如何、离散性与显著性报没报、呈现形式有没有骗人）。典型分工：先跑那个确定"这条声称是什么结构"，确认它确实给出了一个量化结果后，再跑本 skill 审这个量化结果。
- 与 `neuro-genetic-claim-check` 的区别: 那个专管"遗传力估计""脑成像证明"这类**科学背书误读**（尤其"组内遗传力不能解释组间差异"）。本 skill 是通用的数字审查器，不审证据类型；只有当对方搬出遗传力或脑区激活作为数字来源时，才交给那个 skill 做专项拆解。
- 与 `expectation-and-label-engine` 的区别: 那个管**标签与期望如何自我兑现的行为机制**（罗森汉恩、刻板印象威胁、皮格马利翁）。本 skill 只在"分数决定资源分配"这一个接入点上覆盖它——即把测量当作待审计的**干预**来评估；至于标签生效后当事人内部发生了什么，属于那个 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **确认这个数字/分数将被用来做什么决定**
   - 完成标准: 写下"它要支撑的具体决策"与"如果它错了，代价是什么"（谁承担、可逆吗）。
   - 判停条件: 若不用于任何决策、纯作参考 → 只做步骤 5 的呈现形式审计，跳过 2–4、6。

2. **过信度门（重复测一致吗）**
   - 完成标准: 拿到重测 / 平行测验 / 分半内部一致性三者之一的证据，或明确确认拿不到。
   - 判停条件: 若重复测量的结果差得足以改变分类或排名 → 判定不可信，直接跳到步骤 7（不可信必然无效，后三步无需再查）。

3. **过效度门（对"这个目的"有效吗）**
   - 完成标准: 先明确写出"我要用它预测/判断的是什么"，再对内容效度（覆盖欲测领域的全部方面吗）、效标效度（能预测一个外部标准吗）、结构效度（与该构念之外的特征无关吗）分别给出一条证据或标注"无证据"。
   - 判停条件: 若只有"这个工具很科学"的泛泛说明、拿不出针对本次用途的效度证据 → 标记"效度未证"，继续步骤 4 但结论强制降级。

4. **过常模门与标准化门**
   - 完成标准: 答出两问——(a) 这个分数是跟谁比的（常模群体的构成）；(b) 我拿到分数时的施测条件（指导语、时限、能否查资料、是否有人监考、可否重做）与常模建立时是否一致。任一不一致则标注"常模不可比"。

5. **过数字五关 + 做一次呈现形式换算**
   - 完成标准: ① 样本量 ② 离散性度量（全距/标准差） ③ 显著性水平与具体 p 值 ④ 测量工具的操作效度 ⑤ 中数/众数/平均数是否一致——五项逐项打勾，缺项记为"缺失"。随后把关键数字换成另一种等价形式（百分比 ↔ 每 100 人中的具体人数）重读一遍，记录两次感受是否一致。
   - 判停条件: 若五关中缺三项及以上 → 输出"该数字信息量不足，不能进入决策"，跳到步骤 7。

6. **查高利害回路（分数会不会改造被测量者）**
   - 完成标准: 明确回答"这个分数会不会改变被测量者的处境（资源、机会、分组、他人对待方式）"。若会，则列出它可能自我兑现的三条通路（资源通路 / 期望通路 / 自我概念通路），并给出至少一条防自证的对照动作（先记录行为后做定性、主动寻找能否证当前标签的证据、定期拿掉标签重看同一批事实）。

7. **输出分级结论**
   - 完成标准: 给出"可作为决策依据 / 仅作参考 / 不可用"三选一，并附：(a) 未过关的门与关的清单；(b) 把该分数当干预而非测量时的风险提示；(c) 若必须决策，一个比它更便宜或更客观的替代指标建议。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **纯数据加工与计算**（加总、排序、格式转换）——没有"这个数字能不能信"的问题，套用是噪音。
- **不涉及任何量化分数的定性讨论**（"这个方案好不好""团队氛围怎么样"）——应先转 `psych-claim-evidence-audit` 审其声称结构，或直接进入实质讨论。
- **要审的是"X 导致 Y"的因果结构** → 转 `psych-claim-evidence-audit`。本 skill 只审数字与量表，不审因果方向。
- **要拆的是遗传力/脑成像类背书** → 转 `neuro-genetic-claim-check`。

### 作者在书中警告的失败模式
- **换一批人问，结论就翻转（CE08）**: failure_mode 是统计方法完全正确、没有任何计算错误，结论仍然完全错误，因为它只描述了"你问了谁"；mechanism 是抽样框的选择发生在统计开始之前，不在统计推断前提的保护范围内，而自我选择使样本在因变量上就已经不具代表性。最硬的一条推论：**这类错误无法被更大的样本量修复——样本越大，你只是把一个偏差估计得越精确。**
- **"p<.10 只是趋势"（CE09）**: failure_mode 是把"方向符合预期但不显著"用"呈现出……的趋势""边缘显著""虽然未达显著但……"软化包装成结论；mechanism 是 p 值是社会约定而非自然法则，研究者可自由选择检验、变量与切分时，未达显著的结果总能在某个切分下变得显著，且动机上人在结果符合自己假设时会自动降低证据门槛。
- **低算术能力者被呈现形式操纵（CE10）**: failure_mode 是同一份数据换一种呈现形式就给出截然不同的判断；mechanism 是数字素养的作用在于把不同表面形式换算成同一个内部表征，不具备该能力的人只能依赖数字的表面特征做直觉判断。这是书中**唯一自带解药的偏差**——补统计课是真实的防御措施。
- **遗传力估计不能解释组间差异（CE13）**: failure_mode 是把"组内变异归因比例"搬到"组间均值差"上；mechanism 是遗传力是方差分解量，只在同一环境下对同一群体有意义，组间均值差可以百分之百由环境造成同时组内遗传力仍然很高，两者互不蕴含（同批种子分种贫瘠与肥沃土壤的类比）。
- **网络测验信度与效度同时失守（CE34）**: failure_mode 是同一工具重复测结果差到足以改变分类，而它给你的数字看起来很精确；mechanism 是两个独立失效源叠加——工具本身信度不足、参照群体被自我选择扭曲，再叠加一层选择性记忆（只记得最好的那次）。
- **IQ 分数的自我实现（CE35）**: failure_mode 是把 IQ 分数读成"测出了天赋"，忽略了反向回路；mechanism 是测量反作用——当测量结果与资源分配耦合，被测量者会调整行为优化分数，而分配结果又改变其实际能力，于是分数从"指标"变成"干预"。配套事实：分数与问责挂钩后催生作弊（芝加哥公立小学估计 4%–5% 班级存在教师或管理员作弊）。

### 作者的盲点 / 时代局限
- **本书英文版成书于 2014 年，早于 2015 年可重复性危机的大规模重复验证。** 书中被当作定论呈现的若干效应（社会启动、自我损耗、具身认知的部分经典实验、面部反馈假说的强版本、权力姿势）在 2015 年后大面积重复失败。**对本 skill 的直接含义：书中引用的许多"效应"是 2014 年前的单一实验结果，其效应量可能被发表偏差夸大；凡引用书中统计结论，须标注"证据强度：弱/有争议"。**
- **"操作性定义 = 概念本身"这条未被证明的假设**：作者强调操作性定义，却很少讨论"操作效度"——用"距上次进食小时数"定义饥饿，未必等价于你真正关心的那个饥饿。全书实践里经常滑向"分数即构念"。本 skill 的步骤 3 正是对这一盲点的补丁。
- **quantification 偏好**：可测量的构念（IQ、特质分数、反应时）得到更多篇幅，难以量化的（意义感、文化嵌入性）被压缩。因此不要因为"它有分数"就认为它更重要。
- **IQ 等测量构念的客观地位**：第9章讨论了争议，但整体仍把 IQ 当作稳定、有预测力的量在讲；书中对 DSM-5 分类信度争议（Field trials）的呈现也不充分。
- **WEIRD 样本**：常模群体多为西方、受教育、工业化、富裕、民主社会样本，跨群体套用常模会系统性失真。

### 容易混淆的邻近方法论
- **信度 vs 效度**：信度是"跟自己"相关（重复测一致），效度是"跟外部"相关（测到了想测的东西、能预测外部标准）。宣传里的"稳定可靠"只证明了前者。
- **显著 vs 重要 vs 确定**：统计显著只说明差异不像随机波动，不说明效应量大，也不说明结论确定；大样本下微小的、无业务意义的差异也会显著。
- **随机取样 vs 随机分配**：随机**取样**保证样本代表总体（对外可推广），随机**分配**保证组间可比（对内可推因果）。一份报告做了其中一个不等于做了另一个。
- **高利害测评的"中性"幻觉**：只要分数决定资源，测量就带有了干预属性；此时"这个分数准不准"不是唯一问题，"这个分数会造成什么"才是。
