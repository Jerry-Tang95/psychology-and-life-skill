# 神经与基因宣称的检查

## R — 原文 (Reading)

> "如果你看到'科学家发现冲动基因'这样的声明，你就应该弄清楚科学家是如何定义这个词的。这种特异性之所以重要，是因为与'冲动'概念相关的不同行为表现可能有着不同的遗传基础。"
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第3章 行为的生物学和进化基础 > 生活中的批判性思维："这是遗传的"是什么意思

---

## I — 方法论骨架 (Interpretation)

听到"这是基因/大脑决定的"时，先做四层拆解，把标题降级为可评估的实质主张：

1. **定义问（F11）**：科学家怎么定义那个词？"冲动"是不加考虑、无法抑制还是爱冒险？不同定义可能对应不同遗传基础——标题往往把多个定义混为一谈。
2. **机制问（F09）**：凭什么说它与行为有因果关系？光有"A 型人冲动、B 型人不冲动"是事实陈述，给出"阻断该机制后效果消失"才是因果证据。机制阻断检验四步：① 取一个只作用于该机制、且只有这一种作用的阻断剂；② 施加干预 X 看效果；③ 同时施加 X + 阻断剂再看；④ 效果消失→支持"X 经由该机制"，效果仍在→该机制解释被排除。
3. **间接性问（F11 三级还原链）**：把标题从"行为差异(L1) → 脑活动差异(L2) → 基因差异(L3)"逐级还原，看每一级之间的跳跃有没有证据。从 L3 直接跳到 L1（"冲动基因"）都缺了 L2 这一环，每上一级结论强度递减。
4. **交互问（F10 / C42）**：不要停留在"基因 vs 环境"主效应，改用基因型×环境 2×2 交互表。同一基因在不同环境下效果可不同甚至相反（低活性基因型猴子，只有由母亲抚养才表现出高攻击）。真正的解释在交互项，不在"某基因导致 X"。

**遗传力三排除（P34）**：听到"X 的遗传力是 0.6"，正确读法是"**在该群体、该环境下**，X 的变异中约 60% 可归因于遗传差异"；错误读法是"这个人的 X 有 60% 来自基因"，更错的是"所以改变不了"。遗传力高 = 在当前环境下经验能改变的空间相对小，换环境就会变。

**组间差异红线（CE13）**：遗传力是组内变异归因比例，**不能**用来解释组间均值差。身高遗传力高达 0.93–0.96，仍无法据此说某群体身高差异是基因决定的；非裔与白人美国人 IQ 差距在 1972–2002 的 30 年间从约 15 缩到 4–7，本身就说明环境在起作用。

**脑神话双杀（CE11）**："左脑理性、右脑感性，你是哪一种"——左右半球只是加工**风格**不同，无优劣，"开发右脑"无本书依据；"XX 脑区负责 YY"被读成模块化一一对应也是误导，脑像交响乐队协同工作。这类神话的共同来源是把**必要性证据**误读成**充分性证据**（损伤研究只证明某脑区"必需"，公众读成"单独产生"）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 纳洛酮阻断内啡肽（F09 机制阻断范例）
- **问题**: 针灸/安慰剂止痛，宣称"释放内啡肽"——怎么证明？
- **方法论的使用**: 用纳洛酮（已知唯一作用是阻断吗啡和内啡肽与受体结合）。注射后，针灸和安慰剂都失去止痛效果→支持"经由内啡肽释放"。
- **结论**: 只证明"两者同时出现"不够，机制阻断才把"相关"升级为"机制"。

### 案例 2: Caspi 的 5-HTT 基因 × 生活压力（C42）
- **问题**: 同样的打击，为什么有人垮了？
- **方法论的使用**: 新西兰 847 人纵向研究，测 5-羟色胺基因短型(s)/长型(l)；关键设计——**各基因型经历的紧张性刺激相同**。
- **结论**: 组间差异不能归因于生活艰辛程度，只能是基因型使个体对相同经历做出不同反应。这是素质—压力交互论，不是决定论。

### 案例 3: 裂脑人与"左脑解释器"（C28）
- **问题**: 人对自己行为原因的解释可靠吗？
- **方法论的使用**: 右半球看雪景（左手选铁锹）、左半球只看鸡爪；被问为何选铁锹，左脑现场编出"清理鸡舍需要铁锹"。
- **结论**: "我知道我为什么这么做"不是可靠证据。收集行为原因时，不能只依赖当事人对自己动机的陈述。

### 案例 4: 达尔文地雀（C26）
- **问题**: 某个特质"更适应/更先进"吗？
- **方法论的使用**: 大旱年选择大喙、丰年选择小喙，同一物种选择方向随环境反转。
- **结论**: 听到"这个特质更适应"先追问"在什么环境下"；能预测环境反转后的方向变化，才是机制。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 转述科普/新闻："科学家发现 XX 基因""某脑区决定 XX"。
2. 用"这是天生的 / 遗传力 0.6 / 改变不了"解释个人特质或他人表现。
3. 用"左脑人/右脑人""开发右脑"包装课程或测评产品。
4. 用遗传力数字论证群体差异（如种族、性别的能力差距）。
5. 用检测结果（基因检测、脑成像）给人贴"注定如此"的标签。

### 语言信号（用户的话里出现这些就应激活）
- "这是遗传的 / 天生的 / 基因决定的"
- "科学家发现 XX 基因 / 某脑区负责 XX"
- "遗传力 0.6 / 我的 XX 是天生的改不了"
- "左脑理性右脑感性 / 开发右脑"
- English: "genetic determinism", "gene for X", "brain region responsible for"

### 与相邻 skill 的区分
- 与 `psych-claim-evidence-audit` 的区别: 本 skill 专攻"基因/脑"这一类特定宣称的解码；psych-claim-evidence-audit 处理更普遍的研究证据审查（样本/相关vs因果/效应量）。
- 与 `judgment-bias-check` 的区别: 涉及"这是基因/脑决定的"归因偏向时交给本 skill；一般决策偏差交给 judgment-bias-check。
- 与 `abnormality-boundary-judgment` 的区别: 涉及"这是基因/大脑决定的"宣称时本 skill 做证据解码；若话题升级为"算不算障碍/要不要就医"则移交 abnormality-boundary-judgment。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **对"遗传/脑决定"类标题做四问拆解**
   - 完成标准: 逐一回答 定义问 / 机制问 / 间接性问 / 交互问；把标题翻译回"X 基因影响 Y 中介过程"，再判断原标题暗示是否还站得住。

2. **还原三级链条，标出跳跃缺口**
   - 完成标准: 写出 L1 行为 → L2 脑 → L3 基因 的还原链，指出从哪一级直接跳到了哪一级、缺了哪一环证据。

3. **对"遗传力数字"做三排除校验**
   - 完成标准: 确认该数字被正确读作"组内变异归因 + 当前环境依赖"，而非个体成分分解、非家庭成员相同、非不可改变；若被用来解释组间差异，显式标红。

4. **对机制故事做阻断检验**
   - 完成标准: 若存在"X 经由机制 M 起作用"的宣称，给出阻断检验设计（如何隔离并阻断 M），或指出"只有相关、无阻断证据"。

5. **对脑神话做必要性/充分性分离**
   - 完成标准: 遇到"某脑区负责某能力"，区分"该脑区必需"与"该脑区单独产生"，指出协同加工事实，警惕"决定"这类词。

6. **标注证据强度与时代局限**
   - 完成标准: 引用具体基因—行为关联时标注"证据强度：有争议/未复现"；本书出版于2014年、早于2015年后可重复性危机，凡后续存疑的关联须加此标注。

判停条件（进入前先判）: ① 若话题从"是不是基因决定的"升级为"他算不算有障碍、要不要就医" → 终止本 skill，移交 abnormality-boundary-judgment；② 若宣称里没有基因／脑作为证据来源，只是普通研究结论 → 终止本 skill，改用 psych-claim-evidence-audit；③ 若用户想用遗传力数字给某群体定性 → 明确标红"组内遗传力不能解释组间差异"，只做澄清、不做能力排序推论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 用基因/脑决定论给人贴"注定如此"的标签或做道德评判——本 skill 只解码宣称，不产出任何命运结论。
- 遇到"亲友/自己是不是病"的话题——移交 abnormality-boundary-judgment，本 skill 不提供诊断。

### 作者在书中警告的失败模式
- **左右脑神话（CE11）**: "左脑理性、右脑感性""开发右脑"均无本书依据；脑是协同工作，不是模块化一一对应。
- **媒体标题三步失真（CE12）**: 单数"基因"→实际多个；行为词→生理机制词无桥梁；"发现"→实际只是机制推测。读者会主动补齐失真。
- **遗传力误用解释组间差异（CE13）**: 组内变异归因比例被搬去解释组间均值差，统计上正确却支持它根本无法支持的结论。
- **内省不可靠（C28）**: 人对自己行为原因的解释可以是事后编造，不能当作驱动因素的证据。

### 作者的盲点 / 时代局限（必写）
- **本书出版于 2014 年，早于 2015 年后的心理学可重复性危机。** 书中多个候选基因—行为关联（如 DRD4 与冲动、5-HTTLPR 与抑郁/应激反应）在后续大样本元分析中出现争议或未能稳定复现；引用具体基因—行为关联须标注"证据强度：有争议"。
- 社会 priming、自我损耗(ego depletion)等书中提及的若干社会/认知效应同样在可重复性危机中被削弱或撤销；凡涉及此类"机制故事"，优先标注证据强度而非当作既定事实转述。
- 脑成像"反向推理"（从脑区激活反推心理状态）在书中被呈现为直接证据，但该推断需要高度选择性的对应关系，本书未建立；解读脑成像结论须降级为"相关"。

### 容易混淆的邻近方法论
- 普遍的研究证据审查交给 psych-claim-evidence-audit；决策/归因偏差交给 judgment-bias-check；诊断边界移交 abnormality-boundary-judgment。
