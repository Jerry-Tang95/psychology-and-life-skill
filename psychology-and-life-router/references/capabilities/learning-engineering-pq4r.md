# 学习与备考工程

## R — 原文 (Reading)

> 这些技巧是基于在第7章中会讨论的人类记忆的基本原则。它的简称是PQ4R，来自有效学习六个阶段的第一个字母：预习（Preview）、问题（Questions）、阅读（Read）、思考（Reflect）、重述（Recite）、复习（Review）
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第1章 生活中的心理学 > 如何使用本书 > 学习技巧

---

## I — 方法论骨架 (Interpretation)

学习的工程问题可以拆成两半：**存进去**和**取得出来**。绝大多数低效学习，都是把全部时间投在第一半（多读、多看、多划重点），然后指望第二半自动发生。本书给出的核心纠正就是：这两半由不同的条件决定，必须分开设计。

**存进去这一半，决定因素是加工的深度与联结的数量，不是接触的次数。** 判断一个学习动作有没有用，问的是"我有没有对它做出分析、比较、联系、举出自己的例子"，而不是"我看了几遍"。机械复述（在头脑里循环重复）只能防止信息在工作记忆里衰退，不能保证它转入长时记忆；一旦被分心任务打断，18 秒内几乎全部丧失。无结构材料另有两条路可叠加：给随意的配对编一个画面或故事（精细复述），以及用已经熟悉的东西当提取线索（地点法、桩-词法），再辅之以组块压缩容量。

**取得出来这一半，决定因素是匹配。** 匹配分两层：一是**背景匹配**（编码特异性）——提取时的外部背景、内部状态甚至使用的语言，与编码时越像，提取越顺；二是**加工匹配**（传输适宜性加工）——编码时做的加工类型，能不能"传输"到提取时要求的加工类型。语义深编码配语义类任务最好，知觉浅编码配残词补笔反而更匹配。这条的直接推论极其反直觉：**重读训练的是再认，不是回忆**；如果考试要求你合上书凭空写出、或者张口就讲，那你反复重读文档几乎不产生迁移。

PQ4R 就是这两条原则被产品化后的样子。P 预习建结构，Q 提问把标题换成问题以驱动注意力，第一个 R 阅读到能回答问题为止，第二个 R 思考是与已有知识连线，第三个 R 重述是**合上材料凭空回忆并出声回答**（这是把时间从"存"转移到"取"的那个动作），第四个 R 复习是隔一段时间后回看答不出的部分。配套三条调度规则：间隔学习优于突击；固定学习场所（场所与学习形成联结）；站在出题者角度预测题型——因为题型决定加工类型。

一个补充的分配规则来自元记忆：限时且答错倒扣时，先快速通读全部题目给"知道感"打分，把时间优先投给知道感强的题，主动跳过知道感弱的题。

## A1 — 书中的应用 (Past Application)

### 案例 1: 艾宾浩斯与那条著名的遗忘曲线
- **问题**: 想测量记忆随时间衰减的规律，需要一个可重复、可量化的范式。
- **方法论的使用**: 用无意义音节做材料，用**死记硬背（机械复述）**作为唯一的学习方式，反复诵读直到能复现，再测量不同延迟后的保持量。
- **结论**: 得到"最初迅速遗忘、随后趋缓"的曲线；同时得到一个常被忽略的元结论——**这条曲线是机械复述的产物，不是记忆的普遍宿命**。
- **结果**: 作者据此在"考试前仓促填塞"与"机械复述"之间画了等号：考前突击的知识如果不经后续巩固与复习，很快就会被遗忘。它构成了 PQ4R 与间隔学习的反面基线——任何学习方案，先问它是不是在重复艾宾浩斯的做法。

### 案例 2: 斯佩林的部分报告法与彼得森夫妇的复述实验
- **问题**: 短时记忆到底"装得下多少"和"保得住多久"是两件事，但用常规方法测出来的是一个混合数，无法区分"信息没进来"和"进来了没保住"。
- **方法论的使用**: 斯佩林改变**提取窗口**——呈现三行字母后立刻用高/中/低音提示报告哪一行，从而把容量与衰退拆开测量；彼得森夫妇则反过来，给出三个辅音后插入"连续减 3"的分心任务**阻止复述**，从而把"存储"与"靠复述维持"分离开。
- **结论**: 映像记忆容量很大（提示哪一行都能报出），但信息在约半秒内迅速衰退；短时记忆若不靠复述维持，3 秒后已丧失相当多，18 秒后几乎全部丧失。
- **结果**: 给出了一条可迁移的诊断顺序——当一个系统"记不住"时，先分清是"没进来""没保住"还是"提取不到"，三种情况的补救完全不同。对学习者来说，这意味着"我看的时候都懂"这句话没有诊断价值：它测的是再认，不是保住。

### 案例 3: 编码特异性的三组现场证据
- **问题**: 为什么有时候明明学过，换个地方就完全想不起来？提取失败该归因于什么？
- **方法论的使用**: 固定学习材料、只改变编码与回忆时**背景的匹配程度**，观察成绩差异——三组独立证据分别操纵外部背景（潜水员在海滩学与在水下学，分别在两种环境下测验；学生在初次学习的那台钢琴上再演奏）、感觉通道（学习与回忆时呈现同样的气味，四周后测）、以及语言（汉英双语者用哪种语言提问）。
- **结论**: 当提取的背景与编码的背景相匹配时，记忆最为有效；背景不仅指物理环境，也包括内部状态（是否疲劳、是否服药）与使用的语言。
- **结果**: 匹配组成绩接近 50%，且与材料内容毫无关系（单词表与"水"或"潜水"无关）；双语者用英语问就答罗密欧与朱丽叶，用汉语问就答梁山伯与祝英台。由此导出两条可操作推论：学习时主动变换背景（避免只在单一场景编码），以及在考场/现场主动生成线索去还原最初的编码背景。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 备考或考认证，材料多、时间紧，正在纠结"是再读一遍还是做题"。
2. 新人要在两周内接手一套几百页的系统文档、规范或行业白皮书，需要能独立上手而不是"看过"。
3. 准备答辩、面试或演讲——要求**合上材料、张口就能讲**，而当前的准备方式是反复看稿。
4. 反复出现"我看的时候都懂，一合上书就说不出来""学过但用的时候想不起来"。
5. 要设计一场培训、一次汇报或一门课的内容结构，希望听的人真的记住重点。

### 语言信号（用户的话里出现这些就应激活）
- "我看了三遍了还是记不住"
- "我复习的时候都懂，一考试就懵"
- "怎么背才快？""这个要背吗？"
- "看过就忘""学过但想不起来""讲不出来"
- "考前突击还来得及吗"
- 英文: "how should I study for…" / "I've read it three times but can't recall" / "cramming" / "rote memorization" / "retrieval practice" / "spaced repetition"

### 与相邻 skill 的区分
- 与 `memory-reliability-audit` 的区别: 本 skill 是**工程**——如何让未来的记忆更牢、提取更顺（`learning-engineering-pq4r`）；后者是**审计**——评估一段已经存在的回忆能不能当证据（`memory-reliability-audit`）。"我记不住这个知识点"走 #5；"我记得的那个版本是不是真的"走 #4。唯一的接口：编码特异性可以解释为什么某些细节提取不出来，但它提升的是提取成功率，不提升准确度。
- 与 `behavior-change-toolbox` 的区别: #6 改的是**行为**（做不做、做多久、怎么被维持），本 skill 改的是**知识与技能的编码—提取**。"我想坚持每天学习两小时""孩子不肯写作业"走 #6（强化相倚、塑造、程序表）；"这两小时里我该怎么学"走 #5。
- 与 `judgment-bias-check` 的区别: #3 审的是当下的判断与决策是否失准（锚定、可得性、过度自信），不涉及材料的记忆与提取。"我总是高估自己的掌握程度"这类**元认知校准**问题属于 #3，而"我该怎么学"属于 #5。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先定义提取场景（这一步决定后面所有设计）**
   - 问清三件事：考/用的时候要求什么加工类型（合书默写、口头讲、选择判断、还是现场操作）？在什么环境（考场、会议室、生产环境、压力状态）？哪些内容是必须在无提示下想起来的？
   - 完成标准: 已写出一句形如"我需要在 X 场景下，无提示地说出/做出 Y"的提取规格；若用户答不出，先帮他补一个最可能的默认场景再往下走。

2. **P 预习 + Q 提问：把结构变成问题清单**
   - 只看目录、标题、图表、小结，不看正文；然后把每一节标题与关键术语改写成具体问题（"幂等是怎么保证的？""这个概念和 X 有什么区别？"）。
   - 完成标准: 产出一份可勾选的问题清单，条目数等于材料的一级/二级标题数；每个问题都能用材料中的文字回答。

3. **第一个 R 阅读 + 第二个 R 思考：读到能回答问题为止，并强制连线**
   - 带着问题定向读，读到能回答就停，不追求读满页数。读时对每个新概念至少做一次：与已知事物的比较、一个自己的例子、一句"它和 X 最大的不同是什么"。
   - 完成标准: 问题清单中每个问题下面都有一句**自己写的**答案（不是抄原文）；无结构材料（人名、术语、编号、配对事实）已额外施加精细复述（编画面/故事）或记忆术（地点法、桩-词法）或组块。
   - 判停条件: 若材料只需再认不需回忆（如查表型知识、只需认出选项），跳过记忆术与精细复述，改为建立可检索的索引（见 B 段）。

4. **第三个 R 重述：合上材料凭空提取（本 skill 的关键动作）**
   - 每读完一节，合上材料，出声回答自己写的问题，答不出的标红。禁止用"再读一遍"代替这一步。
   - 完成标准: 全程至少有一次"合上资料凭空复述"的动作，且已产出一份标红清单（答不出的条目）。判据：如果一天下来没有任何一次凭空提取，那就只是在重读，不是在学。

5. **第四个 R 复习 + 间隔安排**
   - 把标红项分散到后续多个时段回看；固定一个专用学习场所（场所与学习形成联结，坐下来就容易进入状态）；记录学习时间并画累积图。
   - 完成标准: 已给出一张具体到"哪天、哪个时段、复习哪几条标红项"的间隔表；两次复习之间存在间隔，不存在考前单次突击。

6. **匹配校正：按提取场景反向调整编码方式**
   - 加工匹配：按第 1 步的提取规格练同一种加工（要口头讲，就出声自问自答、找人模拟追问，而不是重读文档；要现场操作，就在真实环境里做一遍）。
   - 背景匹配：复习时主动变换背景（换地点、重排笔记顺序、把主题混着提问）；到现场前用现场的照片、议程、站姿作提取线索还原编码背景。
   - 结构补救（传达类场景）：最重要的内容放开头或结尾；若在中间，就在它前后插入停歇与提问以人为拉开间距，并在结尾总结里再复现一次。
   - 限时策略：先快速通读全部题目给"知道感"打分，时间优先投给知道感强的题；若答错会倒扣，主动跳过知道感弱的题。
   - 完成标准: 已列出"本次学习动作"与"提取要求"的逐条对照表，并至少改掉一条不匹配项（例如把重读改成出声自测）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- **纯查表型知识**：DSM 条目、端口表、命令参数、法规条款——这类知识的正确解法是建立可检索的索引与速查表，而不是把它装进脑子。强行记忆的维护成本高于检索成本。
- **只需再认、不需回忆的任务**：如果工作场景永远提供选项、提示或搜索框，投入深加工与记忆术的收益很低（回忆与再认由不同的提取条件支持）。
- **关键事实依赖记忆术时**：记忆术换来的**可提取性不等于准确性**（用谐音记住的对应关系可能记串）。任何会被用于决策、安全、医疗、财务的关键条目，必须保留一条独立的核对途径。
- **真正的瓶颈是时间或精力，不是方法**：本 skill 优化的是单位时间的产出，不解决"根本没有时间"或"长期睡眠不足"的问题。
- **评估他人或自己的一段回忆是否可信**：那是 `memory-reliability-audit` 的领域，本 skill 的原则（如"复现背景有助于提取"）在取证场景下会被误用为提高准确度的手段。

### 作者在书中警告的失败模式
- **机械复述的低效（CE23）**——failure_mode：靠保持性复述硬灌，考完即忘；支持证据有两条：其一，艾宾浩斯本人用的就是死记硬背，那条著名的"先快后缓"遗忘曲线本身就是机械复述的产物；其二，短时记忆实验里一旦用分心任务阻止复述，3 秒后已丧失相当多、18 秒后几乎全失。mechanism：保持性复述只维持信息在工作记忆中的激活，不建立它与已有知识网络的联结；而长时记忆的提取依赖提取线索的数量与质量。所以"重复 N 遍"这个操作增大的是接触时长，不是线索密度。可操作的转换：把"重复多少遍"换成"建立多少联系"，把"重看"换成"自问意义"。
- **作者自己标注的理论困难**：加工水平理论给出的方向是"加工越深记得越好"，但书中明确承认——**研究者并不总能确切阐明什么使某些加工"浅"、某些"深"**。所以"深加工更好"是方向性原则，不是可精确操作的度量；下游不得把"我加工得很深"当成可验证的指标，只能用它来比较两种具体学习动作的相对深浅。
- **warning_signs（来自原候选条目）**：你的复习方式是反复朗读/反复看而不是自我提问；你能认出答案但合上书说不出要点（再认 ≠ 回忆）；学习内容对你"没有意义"而你没打算给它造意义；你把熬夜突击当成可复用的学习策略。

### 作者的盲点 / 时代局限
- **可重复性危机**：本书英文版成书于 2014 年，早于 2015 年开放科学协作（Open Science Collaboration）的大规模重复验证。书中被当作定论呈现的部分效应——社会启动、自我损耗（ego depletion）、部分具身认知、面部反馈假说的强版本、权力姿势——在 2015 年后大面积重复失败。本 skill 依赖的编码特异性、加工水平与间隔/提取练习属于重复记录相对稳健的一类，但**效应量应被理解为实验室条件下的估计**，且实验室材料多为词表与短文，与真实教材、真实考场的迁移距离未被书中量化。
- **证据基础偏旧**：PQ4R 的原始文献是 Thomas & Robinson（1972），书中的呈现未纳入其后几十年的成分分析与元分析（例如预习环节是否必要、重述与单纯重复测试的对比）。本 skill 因此把"重述/凭空提取"作为不可替代的核心，而把预习与问题环节定位为注意力管理，不宣称它们各自有独立的大效应。
- **未证假设：外部效度默认成立**。实验室证明的编码—提取匹配效应，在高压、限时、真实考场中的迁移强度，书中未给出边界。
- **WEIRD 样本与教育情境**：相关研究的样本绝大多数来自西方大学生，且材料多为无意义词表；对职业培训、成人自学、非字母语言材料的外推是未被检验的。

### 容易混淆的邻近方法论
- **"重读 = 复习"** —— 错。重读训练的是再认，重述训练的是回忆。判断标准只有一条：有没有合上材料。
- **"我能认出答案，说明我记住了"** —— 错。再认与回忆由不同条件支持，书中明确把它们分开定义。以"认得出"为完成标准，是机械复述最典型的伪装。
- **"学习风格（视觉型/听觉型）"** —— 本书**没有**支持按所谓学习风格匹配教学材料的说法。书中支持的是"同时给言语和视觉两套编码"（例如精细复述配视觉表象），这与"按风格选材"是完全不同的主张。
- **"间隔复习 = 多复习几次"** —— 不完整。间隔的价值在于两次提取之间存在遗忘，从而迫使重新提取；连续在同一时段内重复不等于间隔。
- **"记忆术能记住一切"** —— 错。记忆术解决的是线索稀缺，不解决理解与应用；且它带来的可提取性不等于准确性，关键条目必须另设核对途径。
