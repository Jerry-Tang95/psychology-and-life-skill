# 问题表征与证伪

## R — 原文 (Reading)

> "一个问题一般由下面三个方面来定义：（1）初始状态——一开始时不完全的信息或令人不满意的状况；（2）目标状态——你希望获得的信息或状态；（3）操作——为了从初始状态迈向目标状态，你可能采取的步骤。"
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第8章 认知过程 > 问题解决和推理 > 问题解决（问题空间和过程）

---

## I — 方法论骨架 (Interpretation)

本 skill 把"卡住"和"判断"拆成两套可执行的检查。

### 一、表征工具：卡住时先形式化，再换表征
1. **形式化问题空间（F14）**：三问——初始状态（我现在确切在哪、已知什么缺什么）？目标状态（什么算解决了）？操作（允许用哪些手段、有哪些约束）？三者任一没定义好，后续困难多源于此。定义良好的问题交算法；定义不良的（如"设计住宅"）首要任务是把问题本身问清楚。
2. **换表征而非加努力**：形式化后仍卡住，先识别自己默认的编码（"证明"让人联想到数学而卡死），再强制试另一种（"一个和尚上下山两天"重构成"两个和尚同日对走必然相遇"）。
3. **省力**：对解决办法的每个成分单独练到自动化，腾出资源给整体规划。

### 二、证伪工具：让判断有信息量
4. **沃森选择任务找"非 Q"（F15）**：检验"若 P 则 Q"时，直觉找符合证据，逻辑上唯一有信息量的是"非 Q"（结果已发生但前提不满足的项）。抽象形式下多数人做错，换成现实规则（"没有工牌不得进实验室"）就做对了——所以要把检验翻译成团队熟悉的现实约束，只查"非 Q"。
5. **证伪三件套（P04）**：一个解释要被采信须同时通过——① 预测精确到能被推翻；② 收集支持证据前先写下"什么观察会让我放弃它"（因为"找一个支持的理由是容易的"）；③ 能给出让现象发生/不发生的可操作条件（解释力判据是**可控性**，不是听起来合理）。
6. **信念偏见隔离两步（P29 / CE31）**：评估论证必须分两步——第一步只看"从前提到结论的形式是否成立"，第二步才评价"结论我信不信"；结论"听起来很对"恰恰是需要放慢的信号。时间压力下信念偏见显著增强（形式逻辑检查需要意识参与），所以重要评审别排在赶时间的时段。
7. **可得性启发式（C10）**：任何"我凭经验觉得 X 更常见"的判断，本质是在估计"想起例子的容易度"而非"实际频率"。补救是去找客观基数，而不是更用力地回想。

## A1 — 书中的应用 (Past Application)

### 案例 1: 沃森选择任务（F15）
- **问题**: 怎么有效检验"若 P 则 Q"式规则？
- **方法论的使用**: 抽象卡片（元音/偶数）大多数人做错；换成"饮酒须满 18 岁"现实规则就做对了。关键在找"非 Q"——只查"已饮酒但未满 18"那一项。
- **结论**: 把抽象逻辑放进现实情境，演绎能力被"解锁"；缺陷在触发条件不在逻辑能力。

### 案例 2: 信念偏见（P29 / CE31）
- **问题**: 为什么一个逻辑无效的推理，只要结论可信就会被判有效？
- **方法论的使用**: 信念系统启动更快、默认优先；结论可信时逻辑校验不被触发，结论不可信时转入"找反例"模式且受意愿左右。
- **结论**: 在合同/合规/代码评审/事故归因中，必须显式把"这是不是真的"与"这是不是推得出来"拆成两步。

### 案例 3: 可得性启发式——k 在第几位（C10）
- **问题**: 英文文本中"k 开头"还是"第三个字母是 k"的词更多？
- **方法论的使用**: 多数人判"k 开头更多"，实际第三个位置是前者的两倍——因为想起以 k 开头的词远比想起第三个字母是 k 的词容易。国家人口估计也被《纽约时报》提及次数（媒体曝光）而非真实人口驱动。
- **结论**: "想得起"被误当作"更常见"；补救是找客观基数而非更用力回想。

### 案例 4: 和尚上下山（F14 换表征）
- **问题**: 一和尚早上上山、傍晚下山，能否证明"必有一时刻在山路同一点"？
- **方法论的使用**: 把"一个和尚两天"重构为"两个和尚同日对走"，相遇即同点——从时间维度换到路径维度，卡死立即解开。
- **结论**: 我卡在"表征选错了"还是"问题没定义清"，解法完全不同。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 卡在某个问题/项目两个月没思路，想突破。
2. 要检验一条规则、一个假设、一个方案是否成立。
3. 评审方案/报告/合同，判断"这个结论对不对"。
4. 自己或他人凭"经验/直觉"下频率或因果判断。
5. 在 deadline 压力下要做重要逻辑判断。

### 语言信号（用户的话里出现这些就应激活）
- "这个问题怎么破 / 我卡住了 / 没有思路"
- "该验证还是证伪 / 怎么检验这个说法"
- "这结论对不对 / 这个推理有问题吗"
- "我凭经验觉得 X 更常见 / 我直觉是这样"
- English: "stuck on a problem", "how to falsify", "belief bias", "availability heuristic"

### 与相邻 skill 的区分
- 与 `psych-claim-evidence-audit` 的区别: 本 skill 侧重"问题怎么表征、解释怎么证伪"的方法论；psych-claim-evidence-audit 侧重研究证据本身的统计审查（样本/相关vs因果/效应量）。两者都用于"这说法对不对"，但切入层不同。
- 与 `judgment-bias-check` 的区别: 本 skill 用信念偏见/可得性作为具体工具；judgment-bias-check 处理更宽的决策偏差谱系。重叠时本 skill 优先（更聚焦表征与证伪）。
- 与 `number-and-measurement-defense` 的区别: 涉及数字/统计断言的防御交给后者；本 skill 不依赖数字，适用于任何推理与表征场景。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先形式化问题空间**
   - 完成标准: 写出初始状态/目标状态/操作三要素；若用户直接要答案，先补这一步，确认三者定义清晰再谈解法。

2. **仍卡住则换表征，不堆努力**
   - 完成标准: 识别当前默认编码，强制给出一种替代表征（换维度/换主体/换类比），并说明新表征为何可能解锁。

3. **对"若 P 则 Q"式规则做证伪式检验**
   - 完成标准: 把规则翻译成现实约束，列出所有可能违反项，标出"非 Q"，只查"非 Q"；说明为何查符合项无信息量。

4. **对解释跑证伪三件套**
   - 完成标准: 逐条核对 ① 预测可拒吗 ② 先写下反驳路径了吗 ③ 能给出可控条件吗；任一条过不了，标注"尚未证成，只是好听的故事"。

5. **对论证做信念偏见隔离**
   - 完成标准: 遮住结论先审推理链（前提来源、中间分支是否漏），再评价结论；若用户在压力下且对结论有强预感，显式提醒"最易跳过形式检查的时刻"。

6. **对"凭经验更常见"的判断做基数校准**
   - 完成标准: 把"我觉得 X 更常见"重述为"我想起 X 更容易"，并给出查找客观基数的动作，而非更用力回想。

判停条件（进入前先判）: ① 若被审查对象是外部递来的研究证据（"研究表明 X 导致 Y"）→ 终止本 skill，改用 psych-claim-evidence-audit；② 若卡点是分数、指标、统计量的信效度 → 终止本 skill，改用 number-and-measurement-defense；③ 若用户只要一个直觉答案且该判断低风险可逆 → 终止本 skill，不必启动形式化流程。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 把"换表征"当万能钥匙——有些卡住是信息/资源真的不足，需先补齐而非重构。
- 把"证伪三件套"用作否定一切的武器——它是提高解释门槛，不是证明"所有解释都错"。
- 用可得性启发式否定真实的小概率风险（如罕见病筛查）；启发式提示的是"判断偏差"，不替代专业风险评估。

### 作者在书中警告的失败模式
- **只找支持证据（P04）**: "找一个支持的理由是容易的"，先找支持必然一边倒；必须先写反驳路径。
- **把结论可信当推理有效（P29/CE31）**: 信念偏见让"可信→有效、不可信→无效"，在合同/合规/代码评审中危害最大。
- **用"想得起"代"更常见"（C10）**: 可得性启发式使判断基于提取容易度，被媒体曝光等无关因素改变。
- **默认表征卡死（F14）**: 不换编码只加努力，常在原地打转。

### 作者的盲点 / 时代局限
- 本书出版于 2014 年，早于 2015 年后的心理学可重复性危机。本 skill 涉及的"问题空间/沃森选择任务/信念偏见/可得性启发式"属经典且大体稳健的发现，但其**具体效应量**和某些情境下的表现，在近年的大样本复现中有被下调或限定的情况；引用具体数字（如某偏差的幅度）须谨慎，优先引用方法而非精确效应量。
- "控制"作为心理学目标本身带价值立场（谁控制、为谁利益），作者仅在伦理部分有限讨论；本 skill 把"可控性"作为解释力判据时，使用者应意识到这并非价值中立的公理。

### 容易混淆的邻近方法论
- 研究证据统计审查交给 psych-claim-evidence-audit；更宽决策偏差交给 judgment-bias-check；数字/统计断言防御交给 number-and-measurement-defense。
