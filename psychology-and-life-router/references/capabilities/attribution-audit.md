# 归因自检（对人宽容 / 对己反向）

## R — 原文 (Reading)

> 尤其是当你所做的是负面的特质性归因（“这个笨蛋”）时，你应该退后一步并问自己：会不会是情境中的某些事情导致这个行为？你可以把这类练习当作“归因宽容”。……考虑其他人的行为时，你应该努力避免基本归因错误。同样道理，你要考察你对自己行为的归因，以消除自我服务偏差。
>
> — 格里格 / 津巴多，《心理学与生活（第19版）》，第16章 社会心理学 > 建构社会现实

---

## I — 方法论骨架 (Interpretation)

任何一次"他为什么这样 / 我为什么失败"的解释，默认都会朝一个固定方向歪，而且两个方向是相反的：解释别人时偏向"他这个人"，解释自己时偏向"环境"。这不是随机的看走眼，而是因为情境是无形的——你看得到人和他的行为，看不到压着他的排期、考核、依赖和角色。天平一开始就是歪的，扶正需要额外做功。

方向 A（对人）：只在做出**负面**特质归因时启动。捕捉那句内心独白，强制退后一步，问"情境里有什么我还没看见的东西能解释这个行为"，并且要去做研究——去问、去查流程、去看约束，而不是在脑子里替对方编动机。正面归因不必拦（也会高估，但代价小）。

方向 B（对己）：自我服务偏差的默认方向是成功归自己、失败归环境，所以校正要**反向用力**。成功 → 强制找外部/情境因素（题简单、对手弱、时机好、有人帮），目的是保住下一次的努力水平；失败 → 强制找内部可控因素（时间分配、准备方式、某个具体决策），目的是找出下一次能改的杠杆。

判断一个行为该归给"人"还是"场"，用凯利协变三问：区别性（只在这一个情境出现，还是到处都出现）、一贯性（这个情境下他以前也这样吗）、一致性（换别人处在同一情境会不会也这样）。高区别性 + 高一贯性 + 高一致性 → 情境；低区别性 + 高一贯性 + 低一致性 → 特质。三问里最值钱的是"一致性"这一格，因为它逼你去查一条你平时几乎不会主动去查的信息。

对自己成败的归因还要落到三个轴上打分：内部/外部、稳定/不稳定、整体/局部。风险组合是"失败 = 内部 + 稳定 + 整体"（"我从没做对过任何事"），它通向习得性无助与抑郁易感性。改写时翻转任意一个轴都能降低风险，但落点必须是**可变且特定**的因素，而不是笼统地全推给外部。

最后一条判据：这次归因会不会改变我下一次的行动？不会，就是错的归因。

## A1 — 书中的应用 (Past Application)

### 案例 1: 罗斯的"大学投球"问答游戏
- **问题**: 两个人玩问答游戏，一个出题一个答题，谁当提问者由掷硬币决定。这个位置差距会不会被误读成能力差距？
- **方法论的使用**: 游戏结束后，让提问者本人、竞赛者和旁观者三方分别给双方的"一般知识水平"打分。关键设计是：所有人都知道角色是掷硬币决定的，情境优势是公开信息。
- **结论**: 提问者基于自己的阅历出题，情境对他极为有利；但竞赛者和观察者都无视这一点，把差距读成知识水平的差距。
- **结果**: 竞赛者和观察者给提问者打的分高很多，竞赛者给自己的评价甚至略低于平均值——连处在劣势位置的一方也接受了这个错误归因。作者由此说明，人们"即使付出代价也会犯基本归因错误"。

### 案例 2: 普林斯顿—达特茅斯橄榄球赛
- **问题**: 1954 年两队比赛后，两校学生对"谁先动手、谁犯规多"的陈述完全冲突，谁在说谎？
- **方法论的使用**: 不去做取证打脸，而是给两校学生看同一段比赛录像，记录各自对双方犯规次数的判断——把"诚实性"问题换成"选择性编码"问题。
- **结论**: 普林斯顿学生"看到"对方队员的犯规次数是自己球队的两倍；看同样录像的达特茅斯学生"看到"双方犯规次数一样多。
- **结果**: 同一段物理录像产生两套互相矛盾的犯规计数，且各自与观察者所属阵营一致。作者的断言是：人们对复杂的社会情境无法进行客观、无偏差的观察。冲突调解的起点因此不是"谁在撒谎"，而是"双方都在做选择性编码"。

### 案例 3: 40 名精神病医生预测米尔格拉姆实验
- **问题**: 普通人会不会在权威指令下对他人施加致命电击？米尔格拉姆请 40 名精神病医生做预测。
- **方法论的使用**: 专家依据"人格特质"下判断——只有某种程度上有些异常的个体才会使用最高强度电击。
- **结论**: 预测大部分人不会超过 150 伏；300 伏时不到 4% 仍服从；450 伏时只有约 0.1%。
- **结果**: 实际结果是达到 300 伏时仍无参与者退出，65% 的人施加了最高值 450 伏。作者的诊断是：专家的评价"建立在人们人格特质的基础上……他们忽视了这种特殊情境对人的思维和行为的影响"。专业训练不提供免疫力，它强化的是"识别个体异常"这一技能，从而放大而非抵消这个偏差。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?
1. 同事、下属、合作方出现一次让你不满的行为，你脑中冒出形容词（懒、不上心、不负责、不专业）。
2. 你要复盘一次自己的成功，准备把它固化成"方法论"复制到别处。
3. 你要复盘一次自己的失败或失误，需要决定下一步到底改什么。
4. 绩效评估、招聘判断、追责会议——任何把结果归到某个人的场合。
5. 冲突双方陈述互相矛盾（跨团队扯皮、合作破裂、朋友翻脸），你在判断谁说得对。
6. 连续受挫后开始出现"我从来就不行""这事没救了"这类整体性的自我概括。

### 语言信号（用户的话里出现这些就应激活）
- "他就是这种人" / "他就是不上心" / "这个人不行"
- "这事儿不怪我，是他们拖后腿" / "要不是环境这样，我早就……"
- "我从来没做成过这种事" / "我果然不适合" / "我怎么努力都没用"
- 英文: "that's just who he is" / "he's just lazy" / "it wasn't my fault, the situation was impossible" / "I'm just not a ... person"

### 与相邻 skill 的区分
- 与 `situational-force-audit` 的区别: 那个处理"一群人为什么一致地做出他们单独不会做的事"、以及"怎么改这个结构"——对象是系统与制度，产出是要拧的旋钮（角色、规范、从众、服从、群体思维）。本 skill 处理"一次已经发生的行为，原因该归给谁"——对象是单个行为，产出是修正后的归因。问"他为什么这么做 / 我为什么失败"用本 skill；问"为什么这里的人普遍都这样 / 怎么让这个群体制止这种事"用 `situational-force-audit`。
- 与 `judgment-bias-check` 的区别: 那个的输入是概率、估计、方案选择与数字（锚定、可得性、框架、过度自信）；本 skill 的输入是**原因**。当你在估一个数或选一个方案时用 `judgment-bias-check`；当你在解释一个已发生的行为时用本 skill。
- 与 `expectation-and-label-engine` 的区别: 那个是向前看的——你的期望如何改变对方的表现（自证预言、刻板印象威胁）；本 skill 是向后看的——已发生的行为如何被解释。
- 与 `bystander-intervention` 的区别: 那个处理"有一个具体的人正在等待帮助，接下来谁动手"，产出是把责任钉到一个人身上的一句话；本 skill 处理原因归属，产出是修正后的解释。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **锁定对象与方向**
   - 明确写下：这次要解释谁的行为（他人 / 自己），以及结果是成功还是失败。
   - 完成标准: 产出一行可复核的文字——"方向 = 对人/对己；事件 = ___；结果 = 成功/失败"。
   - 判停条件: 若对象是一群人的一致行为，或一个组织/制度的设计问题（"为什么整个部门都在造假""会议为什么全票通过"），跳到 `situational-force-audit`。

2. **捕捉那句内心独白**
   - 把你（或用户）对这件事的第一解释原样写下来，不做任何修饰。
   - 完成标准: 写出的句子可被第三人读出情绪与指向（例如"他就是不上心"）。
   - 判停条件: 若原句里不含任何形容词或特质词、全是条件描述，说明已经在做情境归因，跳到步骤 5。

3. **方向 A（对人）：强制补情境，去做研究而不是编动机**
   - 列出至少三条你尚未亲眼看见、但可能推动该行为的情境约束：排期与并发任务、激励与考核口径、资源与上游依赖、他人介入、角色与权限、流程缺陷。
   - 完成标准: 三条全部写成"描述条件的句子"（有主语 + 有约束），且其中至少一条是**去问过或查过**得来的，不是推测出来的。
   - 判停条件: 若能写出的约束少于两条，判定"信息不足"，结论挂起为待查，不下判断。

4. **方向 B（对己）：反向用力**
   - 成功 → 强制写出三条外部/情境因素；失败 → 强制写出一条内部且可控的因素，并转成下一步的具体动作。
   - 完成标准: 成功侧三条外部因素各自可独立成立（删掉任意一条，另外两条仍然成立）；失败侧那一条写成"我下次会改变的具体动作 + 时间点"。
   - 判停条件: 若失败侧写不出任何内部可控因素，回到步骤 3，用同样的口径再查一遍外部证据，确认不是把不可控的当成了可控。

5. **凯利协变三问（判断是"人"还是"场"）**
   - 区别性：这个行为只在这一个情境出现，还是在很多情境都出现？
   - 一贯性：在这个情境里，他以前也这样吗？
   - 一致性：换成别人处在同样情境，会不会也这样？
   - 完成标准: 三格都有答案，且"一致性"这一格有外部参照（同行的做法、其他人的数据、替代方案的实际结果），不是凭印象。
   - 判定: 高区别性 + 高一贯性 + 高一致性 → 情境归因；低区别性 + 高一贯性 + 低一致性 → 特质归因。

6. **对自己的失败做三轴打分（风险检查）**
   - 把归因标为 内部/外部、稳定/不稳定、整体/局部，然后改写。
   - 完成标准: 三轴各打一个值，且改写后的版本至少翻转其中一个轴，落点必须是**可变且特定**的因素（准备方式、时间分配、某个具体决策），而不是笼统推给外部。
   - 判停条件: 若出现"内部 + 稳定 + 整体"并伴随持续低落与功能下降，这超出归因练习能处理的范围，转 `abnormality-boundary-judgment` 并建议寻求专业帮助，不要在这里继续做认知改写。

7. **验收：这次归因会不会改变我下一次的行动？**
   - 完成标准: 能说出一个明确的、与旧归因不同的下一步动作。
   - 判停条件: 若答案是否（归因不改变任何行动），判定这次归因无效，回到步骤 2 重写。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill
- 你在**设计或改造**一个群体的结构（角色分配、规范、会议流程、问责链条）时——那是 `situational-force-audit` 的活。本 skill 只解释已发生的行为，不产出制度设计。
- 事件仍在实时发生、你正处在情绪高峰（刚吵完架的几分钟内）——作者自己指出，非自我服务判断需要调动负责监控意图与自控的脑区，要付出额外的心理努力。校正必须安排到事后专门的复盘时间，不能靠顺手一想。
- 涉及真实伤害的追责与法律/合规判定——归因自检是**降低错误归因**的工具，不是免责工具，不能用来把他人的故意伤害重新解释成"情境所迫"。
- 评价你刚认识、只有一次观察样本的人——区别性与一贯性两格根本填不出来，三问必然失效，此时唯一诚实的结论是"样本不足"。

### 作者在书中警告的失败模式
- **failure_mode（CE47）**: 40 名精神病医生预测米尔格拉姆实验的服从率，估计 300 伏时不到 4%、450 伏时约 0.1% 的人会继续；实际结果是 300 伏时无人退出，65% 的人施加了最高值 450 伏。作者的诊断是，专家的评价"建立在人们人格特质的基础上……他们忽视了这种特殊情境对人的思维和行为的影响"。错误方向恰好落在"低估情境、高估人格"这一侧。
- **mechanism**: 基本归因错误是知觉性的，不是推理性的——观察他人时，人在知觉前景、情境在知觉背景，而"你看不到社会规范，你只能看到它们引发的行为"，所以天平一开始就是歪的。作者的提醒是"往往需要做些'研究'才能发现行为的情境根源"。专业人员失败得更彻底，是因为专业训练强化的是"识别个体异常"的技能，它放大而非抵消这个偏差。推论：预测任何人（包括你自己）在**未曾经历过的情境**中的行为，准确率都极低，无论专业水平。
- **配套的自检信号**：你的解释用的是形容词（他懒、他坏、他有领导力）而不是描述条件的句子；你说不出对方所处情境的三条具体约束；你在判断一个你从未处过的情境中的人（"换成我肯定不会"）。

### 作者的盲点 / 时代局限
- 本书英文版成书于 2014 年，早于 2015 年可重复性危机的大规模重复验证。本 skill 引用的米尔格拉姆服从实验虽有伯格 2009 年的部分重复（在 150 伏处停止：原实验 82.5% 的人继续，重复中 70% 继续），整体仍属"经典但需谨慎引用"的区间。
- 凯利协变模型描述的是**人们应当如何归因**的规范模型，而大量研究表明人在真实情境中并不会系统地去收集这三个维度的信息。它是一张检查表，不是对实际心理过程的描述——不要把它当成"人就是这么判断的"。
- 作者用美日奥运报道研究承认了基本归因错误是文化变量的函数（独立型自我构念的文化更强），但全书证据库仍以 WEIRD 样本（尤其美国大学生）为主。中文语境的使用者要注意：相互依赖型自我构念下 FAE 更弱，而"失败归自己"的倾向可能本来就偏强，此时步骤 6 的改写方向应偏向"把过度内部化改回特定化"，而不是一律再加内部归因。
- 书中"起作用的是解释，不是真相"这一归因风格结论（第14章）在临床上有力，但效应量普遍偏小且多为相关设计，不要读成"改个说法就能解决抑郁"。

### 容易混淆的邻近方法论
- 与"换位思考 / 共情"：换位思考是在脑子里替对方编一个动机，作者要求的恰恰是相反的动作——**去做研究**（去问、去查流程、去看约束）。你想不出对方的情境约束，不等于它不存在。
- 与"归因训练 / 积极心理学式鼓励"：本 skill 的落点是**找出下一次能改的杠杆**，不是让自己好受一点。把失败全部推给外部是自我服务偏差的原型，不是本 skill 的产物。
- 与 `situational-force-audit`：见 A2 区分。两者都会提到米尔格拉姆，但用法不同——本 skill 用它证明"专家把情境问题读成了人格问题"（归因方向错误），那个用它证明"服从由情境变量控制"（结构可设计）。
