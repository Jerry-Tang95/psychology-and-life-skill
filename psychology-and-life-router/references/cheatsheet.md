# 决策规则速查 — 《心理学与生活（第19版）》

| 能力 | 一句话规则 |
|---|---|
| 心理研究证据审查 | 给概念下操作性定义、把相关改写成三个因果故事、追问"和什么比"、清点残留的备选解释。 |
| 判断与决策偏差自检 | 先决定要不要启动慢系统，再依次过可得性、代表性、锚定、框架、信念偏见、过度自信六道关。 |
| 归因自检（对人宽容 / 对己反向） | 评价他人时默认加情境、只对负面特质启动归因宽容；评价自己时反向用力——成功找外部、失败摆条件。 |
| 学习工程化（PQ4R） | 用精细复述 + 编码特异性 + 提取练习把材料变成"合上书能讲出来"，而非反复重读。 |
| 行为改变工具箱 | 用三项相倚 + 塑造 + 程序表设计行为改变的后果结构，替代惩罚与意志力；先做功能分析再谈干预。 |
| 压力认知评价与应对 | 走完认知评价三阶段，按可控性选路径——可控走问题聚焦，不可控走情绪聚焦；再按"类型×匹配"配社会支持。 |
| 数字与测量防御 | 过一个数字之前先过信度、效度、常模、标准化四道门，再过样本量、离散性、显著性、操作效度、三均值一致性五关。 |
| 问题表征与证伪 | 卡住时先形式化问题空间（初始/目标/操作）再换表征；审查解释时用沃森选择任务找"非 Q"。 |
| 记忆可靠性审查 | 记忆是重构而非回放——自信不携带准确度信息，且事后信息、暗示与复述本身都会改写它。 |
| 神经与基因宣称的检查 | 把耸动的基因/脑科学标题降级为可评估的实质主张——遗传力不等于宿命，也不解释组间差异。 |
| 心理异常判断的边界 | 本能力的目的是阻止给自己或他人贴诊断标签——判"异常"没有充要条件，只有连续体与社会协商的边界。 |
| 旁观者干预 | 打断责任扩散——求助要点名到人并给出具体任务，旁观者要把责任收拢回自己身上。 |
| 期望与标签的自证效应 | 你的期望通过四步行为链把标签变成事实——所以改变对方表现的杠杆常在你自己的期待里。 |
| 说服抵御与顺从设计 | 走中心路径还是外周路径取决于动机与能力；抵抗套路要认得出互惠、承诺一致、稀缺、门槛技术。 |
| 情境力量审查 | 识别并调整五类结构参数——角色、规范、从众、群体决策、服从——产出是"该拧哪个旋钮"，不是"谁有问题"。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
