# 术语表 — 心理学与生活（第19版）蒸馏

> 本表 distilled 自 `candidates/glossary.md`，仅保留跨 skill 高频复用的核心概念。

## 方法论 / 推理
- **问题空间 (problem space)**：由初始状态、目标状态、操作三要素定义的问题表征（F14）。
- **证伪 (falsification)**：一个解释须预测精确可拒、先写反驳路径、能给出可控条件，方被采信（P04）。
- **沃森选择任务 (Wason selection task)**：检验"若 P 则 Q"时，唯一有信息量的是找"非 Q"（F15）。
- **信念偏见 (belief bias)**：把"结论可信"误当"推理有效"；时间压力下更强（P29 / CE31）。
- **可得性启发式 (availability heuristic)**：判断基于"想得起"而非"实际频率"（C10）。

## 研究证据
- **相关 ≠ 因果**：仅共变不足以建立因果，需机制阻断或随机分配（F09 / psych-claim-evidence-audit）。
- **机制阻断检验**：用只作用于该机制的阻断剂，验证"X 经由机制 M 起作用"（F09）。
- **遗传力 (heritability)**：组内变异归因比例，≠ 个体宿命、≠ 可解释组间差异（P34 / CE13）。

## 社会 / 认知
- **基本归因错误 (fundamental attribution error)**：解释他人行为时低估情境、高估特质（attribution-audit）。
- **自我服务偏差 (self-serving bias)**：把成功归己、失败归外（attribution-audit）。
- **自我实现预言 (self-fulfilling prophecy)**：对未来的预测改变互动，直至成真（expectation-and-label-engine）。
- **刻板印象威胁 (stereotype threat)**：被提醒群体差异会拉低该群体表现（expectation-and-label-engine）。
- **精细可能性模型 (ELM)**：中心路径（看论点强弱）vs 外周路径（看表面线索）（persuasion-and-compliance）。
- **登门槛 (foot-in-the-door)**：先小请求后大请求，提升顺从（persuasion-and-compliance）。
- **认知评价 (cognitive appraisal)**：初级/二级/重新评价，压力应对取决于可控性（stress-appraisal-coping）。
- **素质—压力模型 (diathesis-stress)**：易感性 × 环境压力交互，非先天 vs 后天二选一（abnormality / neuro-genetic）。

## 边界 / 安全
- **诊断边界**：无单一充要指标区分异常/正常；本 skill 只转介不诊断（abnormality-boundary-judgment）。
- **自杀信号红线**：任何提及/暗示自杀立即转介专业帮助，不做分析（abnormality-boundary-judgment）。
- **神经神话**："左脑理性/右脑感性""开发右脑"无本书依据，脑为协同工作（CE11 / neuro-genetic-claim-check）。
- **可重复性危机**：本书 2014 年出版，早于 2015 后危机；引用具体基因—行为关联须标注证据强度（多 skill B 段）。
