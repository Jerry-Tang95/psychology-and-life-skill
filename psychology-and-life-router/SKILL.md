# 《心理学与生活（第19版）》 — 来源路由入口（compact pack）

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 心理疾病的诊断与治疗（本书方法不可替代专业评估）
- 司法鉴定、创伤记忆取证、认知障碍评估等专业场景
- 神经解剖、感觉生理、心理学史等纯知识性内容（作背景，见 GLOSSARY）
- 用本书方法操纵或欺骗他人

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 概念不落到操作性定义上，争论就没有裁判
2. 相关不能推因果，第三变量是观察性研究的头号敌人
3. 观察自带偏见，须用标准化、双盲与安慰剂控制剔除
4. 记忆是重构而非回放，自信不携带准确度信息
5. 人靠启发式做判断，偏差是系统性的而非随机的
6. 行为的改变靠强化相倚与程序表，比惩罚和意志力可靠
7. 压力的影响取决于认知评价与应对方式，不取决于事件本身

## 边界与判停

- 用户提及自伤、自杀念头或急性精神症状 → 停止方法论输出，立即建议专业帮助
- 话题升级为"是不是障碍 / 要不要就医 / 该不该用药" → 停止自行分析，转介专业人士
- 涉及创伤记忆、司法鉴定、认知障碍评估 → 停止使用记忆审查工具，转介专业人士
- 用户只是要查知识点（如"什么是操作性定义"） → 直接回答，不启动审查流程
